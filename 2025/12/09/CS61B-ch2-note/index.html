Class Methods vs. Instance Methods

类方法也叫做静态方法，实例方法也称为实例方法。

只有这两种方法。

出于要求，请保证Java的静态变量由类名而不是实例名访问。

例如，你应该使用 Dog.binomen ，而不是 d.binomen 。

虽然 Java 技术上允许你使用实例名称来访问静态变量，但这是一种不好的风格，容易引起混淆，我认为这是 Java 设计者的一个错误。

有关main（）方法的解释

对于main的各个部分，我们有如下解释

  • public : 到目前为止，我们所有的方法都以这个关键字开头。（看起来好像没说什么）
  • static : 这是一个静态方法，不与任何特定实例相关联。
  • void : 它没有返回类型。
  • main : 这是方法的名称。
  • String[] args : 这是传递给 main 方法的参数。

总结

  • Java所有的代码都必须放于类中
  • 静态方法（类方法）和非静态方法（实例方法）是唯二被允许的方法。
  • 静态方法的调用由类名调用，非静态方法的调用由示例调用
  • 定义构造函数会使得实例的定义更加方便，new关键词
