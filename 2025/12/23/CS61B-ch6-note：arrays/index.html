Array Basics

到目前为止，我们已经看到了如何利用递归类定义来创建一个可扩展的列表类，包括 IntList 、 SLList 和 DLList 。在本书接下来的两个章节中，我们将讨论如何使用数组来构建一个列表类。

本书的这一部分假设你已经熟悉数组，并且不打算成为它们语法的全面指南。

为了最终构建一个可以存储信息的列表，我们需要某种方式来获取内存框。之前，我们看到过如何通过变量声明和类实例化来获取内存框。(第三节中的内容）例如：

  • int x; 给我们一个 32 位内存框，用于存储 int。
  • Walrus w1; 给我们一个 64 位内存框，用于存储 Walrus 引用。
  • Walrus w2 = new Walrus(30, 5.6); 让我们获得 3 个内存框。一个 64 位的 Walrus 引用存储框，一个 32 位的 Walrus 大小存储框，以及一个 64 位的 Walrus 牙大小存储框。

数组是一种特殊的对象，由编号的内存框序列组成。这与类实例不同，类实例具有命名的内存框。要获取数组的第 i 个元素，我们使用方括号表示法，就像我们在 HW0 和 Project 0 中看到的那样，例如使用 A[i] 来获取 A 的 i 个元素。

数组包含：

  • 一个固定的整数长度，N
  • 一个包含 N 个内存框的序列（N = 长度），其中所有框的类型相同，编号从 0 到 N - 1。

与类不同，数组没有方法（但是数组有属性）

Array Creation

数组创建有三种有效表示法。尝试运行下面的代码并看看会发生什么。

  • x = new int[3];

  • y = new int[]{1, 2, 3, 4, 5};

  • int[] z = {9, 10, 11, 12, 13};

这三种表示法都会创建一个数组。第一种表示法，用于创建 x ，会创建一个指定长度的数组，并用默认值填充每个内存框。在这种情况下，它会创建一个长度为 3 的数组，并用默认的 int 值 0 填充这 3 个框。

第二种表示法，用于创建 y ，会创建一个刚好能容纳指定初始值的数组。在这种情况下，它会创建一个长度为 5 的数组，包含这五个特定的元素。

第三种表示法，用于声明和创建 z ，与第二种表示法行为相同。唯一区别在于它省略了 new 的使用，并且只能与变量声明结合使用。

这些表示法没有哪一种比另一种更好。

Arrays vs. Classes

数组和使用类都可以用来组织一堆内存盒子。在两种情况下，内存盒子的数量都是固定的，即数组的长度不能改变，就像类字段不能添加或删除一样。

数组中的内存盒子和类中的内存盒子的主要区别：

  • 数组盒子是编号的，使用 [] 符号访问，而类盒子是命名的，使用点符号访问。
  • 数组框必须全部是同一类型。类框可以是不同类型。
