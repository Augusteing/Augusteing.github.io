要运行 Hello.java 中的代码，我们首先使用命令 javac HelloWorld.java 将代码编译成 .class 文件。然后，使用命令 java HelloWorld 来运行代码。

为什么必须要编译为.class文件？

使用 .class 文件有多种原因，我们在这里仅简要提及。首先， .class 文件经过类型检查，使得分布式代码更加安全。它们执行起来也更高效，并且在涉及知识产权的情况下保护真实的源代码。在本笔记中，我们不会深入讨论 .class 文件，除了知道它们是在编译之后生成的。

Static Typing

Java 是一种静态类型语言，这意味着所有的变量、参数和方法都必须声明类型。声明之后，类型将永远不能改变。表达式也有隐式类型；例如，表达式 3 + 5 的类型是 int 。

因为所有类型都是静态声明的，编译器会在程序运行之前检查类型是否兼容。这意味着类型不兼容的表达式会在编译时失败，而不是在运行时导致程序崩溃。（请回顾Java的工作流）

静态类型的优势包括：

  • 在编码过程中更早地发现类型错误，减少程序员的调试负担。

  • 避免对最终用户产生类型错误。

  • 使代码更易于阅读和理解。（对于初学者这一点相当重要）

  • 避免昂贵的运行时类型检查，使代码更加高效。

当然任何事物的矛盾对立统一，静态类型的劣势在于：

  • 更冗长的代码。（相对于python这一点Java会很明显）  
  • 不够通用的代码。

Java 的一个最重要的特性是所有的变量和表达式都有所谓的类型。Java 变量只能包含该类型的值，且只能包含该类型的值。此外，变量的类型一旦确定，就永远不会改变。（你在之后的例子中会有更深刻的感悟的）

第一个会成功；第二个会给出编译错误。由于 Java 是强类型语言，如果你告诉它 h 是一个字符串，它就可以连接元素并返回一个字符串。但当 h 是一个 int 时，它不能将数字和字符串连接起来并返回一个数字。

Python 不限制类型，也无法假设你想要的类型是什么。 x = 5 + "horse" 应该是一个数字？还是字符串？Python 不知道，所以会报错。

在这种情况下， System.out.println(5 + "horse"); ，Java 将参数视为字符串连接，并输出 “5horse” 作为你的结果。或者，更有用的是， System.out.println(5 + " "); 会在你的 “5” 后面打印一个空格。
