Introduction  引言

在本节中，我们将建立对 反向传播 (Backpropagation) 的直观理解并掌握相关专业技能。反向传播是一种通过递归应用 链式法则 (Chain Rule) 来计算表达式梯度的方法。理解这一过程及其细节对于理解、有效开发、设计和调试 神经网络 至关重要。

我们研究的核心问题如下：给定一个函数 $f(x)$，其中 $x$ 是输入向量，我们需要计算 $f$ 在 $x$ 处的梯度（即 $\nabla f(x)$）。

我们关注这个问题的主要原因在于，在神经网络的具体案例中，$f$ 对应于 **损失函数 ($L$)**，而输入 $x$ 由训练数据和神经网络权重组成。例如，损失函数可以是 SVM 损失函数，输入包括训练数据 $(x_i, y_i), i=1\dots N$ 以及权重和偏置 $W, b$。

注意（这是机器学习中常见的情况），我们通常认为训练数据是给定且固定的，而权重是我们可控的变量。因此，尽管我们可以通过反向传播轻易计算输入样本 $x_i$ 的梯度，但在实践中，我们通常只计算参数（如 $W, b$）的梯度，以便用于 参数更新。不过，正如课程稍后将涉及的，计算 $x_i$ 的梯度有时仍有帮助，例如用于可视化和解释神经网络的行为。

如果你在加入本课程时已能熟练运用链式法则推导梯度，我们仍鼓励你浏览本节内容。因为它提供了一种鲜少涉及的视角——将反向传播视为 实值电路 (Real-valued Circuits) 中的 **反向流动 (Backward Flow)**。你从中获得的见解将对整个课程的学习大有裨益。

Simple expressions and interpretation of the gradient

让我们从简单的开始，以便为更复杂的表达式建立符号和约定。考虑两个数字的简单乘法函数 $f(x, y) = xy$。推导任一输入的偏导数只需简单的微积分知识：

$$f(x, y) = xy \quad \rightarrow \quad \frac{\partial f}{\partial x} = y \quad \frac{\partial f}{\partial y} = x$$
让我们从简单的开始，以便为更复杂的表达式建立符号和约定。考虑两个数字的简单乘法函数 $f(x, y) = xy$。推导任一输入的偏导数只需简单的微积分知识：

$$f(x, y) = xy \quad \rightarrow \quad \frac{\partial f}{\partial x} = y \quad \frac{\partial f}{\partial y} = x$$

解释。请记住导数告诉了你什么：它们表示函数在某一点附近无限小区域内相对于该变量的变化率：

$$\frac{df(x)}{dx} = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

关于技术细节的注意事项是，左侧的除号与右侧的除号不同，它不代表除法。相反，该符号表示算子 $\frac{d}{dx}$ 被应用于函数 $f$，并返回一个不同的函数（导数）。理解上述表达式的一个好方法是，当 $h$ 非常小时，函数可以被直线很好地近似，而导数就是它的斜率。换句话说，每个变量上的导数告诉你整个表达式对其值的敏感度。例如，如果 $x=4, y=-3$，则 $f(x,y) = -12$，且 $x$ 上的导数 $\frac{\partial f}{\partial x} = -3$。这告诉我们，如果我们把这个变量的值增加一点点，对整个表达式的影响将是使其减小（由于负号），且变化量是该增加量的三倍。这可以通过重新排列上述方程看出（$f(x+h) = f(x) + h \frac{df(x)}{dx}$）。类似地，因为 $\frac{\partial f}{\partial y} = 4$，我们预期将 $y$ 的值增加非常小的量 $h$ 也会增加函数的输出（由于正号），且增加量为 $4h$。

每个变量上的导数告诉你整个表达式对其值的敏感度。

如前所述，梯度 $\nabla f$ 是偏导数的向量，因此我们有 $\nabla f = [\frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}] = [y, x]$。尽管梯度在技术上是一个向量，为了简单起见，我们经常使用诸如“$x$ 上的梯度”之类的术语，而不是技术上正确的短语“$x$ 上的偏导数”。

我们也可以推导加法运算的导数：

$$f(x, y) = x + y \quad \rightarrow \quad \frac{\partial f}{\partial x} = 1 \quad \frac{\partial f}{\partial y} = 1$$

也就是说，无论 $x, y$ 的值是多少，$x, y$ 上的导数都是 1。这也是合理的，因为增加 $x$ 或 $y$ 中的任何一个都会增加 $f$ 的输出，并且这种增加的比率独立于 $x, y$ 的实际值（不像上面的乘法情况）。我们在课程中会经常使用的最后一个函数是 $max$ 运算：

$$f(x, y) = \max(x, y) \quad \rightarrow \quad \frac{\partial f}{\partial x} = 1(x >= y) \quad \frac{\partial f}{\partial y} = 1(y >= x)$$

也就是说，较大输入上的（次）梯度是 1，而另一个输入上的梯度是 0。直观地说，如果输入是 $x=4, y=2$，那么 max 是 4，且函数对 $y$ 的设置不敏感。也就是说，如果我们将它增加一个微小的量 $h$，函数将保持输出 4，因此梯度为零：没有影响。当然，如果我们把 $y$ 改变一个很大的量（例如大于 2），那么 $f$ 的值就会改变，但导数并没有告诉我们关于输入发生这种巨大变化后的影响；正如定义中的 $\lim_{h \to 0}$ 所表明的那样，它们仅对输入的微小、无限小的变化提供信息。

使用链式法则的复合表达式

现在让我们开始考虑涉及多个复合函数的更复杂表达式，例如 $f(x, y, z) = (x + y)z$。这个表达式仍然简单到可以直接微分，但我们将采用一种特定的方法来处理它，这将有助于理解反向传播背后的直觉。具体来说，请注意这个表达式可以分解为两个表达式：$q = x + y$ 和 $f = qz$。此外，正如上一节所见，我们知道如何分别计算这两个表达式的导数。$f$ 只是 $q$ 和 $z$ 的乘法，所以 $\frac{\partial f}{\partial q} = z, \frac{\partial f}{\partial z} = q$，而 $q$ 是 $x$ 和 $y$ 的加法，所以 $\frac{\partial q}{\partial x} = 1, \frac{\partial q}{\partial y} = 1$。然而，我们不一定关心中间值 $q$ 上的梯度——$\frac{\partial f}{\partial q}$ 的值并不是很有用。相反，我们最终感兴趣的是 $f$ 相对于其输入 $x, y, z$ 的梯度。链式法则告诉我们，将这些梯度表达式“链接”在一起的正确方法是相乘。例如，$\frac{\partial f}{\partial x} = \frac{\partial f}{\partial q} \frac{\partial q}{\partial x}$。在实践中，这只是两个保存了梯度的数值的乘法。

译者按：这里实际上为 $x$ 对 $f$ 的影响，$x$ 通过作用于 $q$ 影响函数值

这种计算也可以通过电路图直观地展示出来。左侧的实值“电路”展示了计算过程的视觉表示。前向传播 (Forward pass) 计算从输入到输出的数值（图中以绿色显示）。随后，反向传播 (Backward pass) 从末端开始，递归地应用链式法则来计算梯度（图中以红色显示），一直回传至电路的输入端。我们可以将梯度想象为在电路中反向流动。

请注意，反向传播是一个美妙的局部过程。电路图中的每个门单元接收一些输入，并能立即计算两件事：1. 它的输出值；2. 其输出相对于输入的局部梯度。请注意，门单元可以完全独立地完成这项工作，而无需知道它所嵌入的整个电路的任何细节。然而，一旦前向传播结束，在反向传播期间，门单元最终将获得其输出值相对于整个电路最终输出的梯度。链式法则指出，门单元应该获取该梯度，并将其乘以它为所有输入计算的每一个梯度。

由于链式法则而产生的这种额外的乘法（针对每个输入），可以将一个孤立且相对无用的门单元转变为复杂电路（如整个神经网络）中的一个齿轮。

让我们再次参考该示例，以直观地理解其工作原理。加法门接收输入 $[-2, 5]$ 并计算输出 $3$。由于该门计算的是加法运算，其两个输入的局部梯度均为 $+1$。电路的其余部分计算出的最终值为 $-12$。在反向传播过程中（链式法则在电路中递归地向后应用），加法门（作为乘法门的输入）得知其输出的梯度为 $-4$。如果我们把电路拟人化，认为它想要输出更高的值（这有助于直观理解），那么我们可以认为电路“想要”加法门的输出变得更低（由于负号），且“力度”为 $4$。为了继续递归并链接梯度，加法门获取该梯度并将其乘以其输入的所有局部梯度（使得 $x$ 和 $y$ 上的梯度均为 $1 * -4 = -4$）。请注意，这产生了预期的效果：如果 $x, y$ 减小（响应它们的负梯度），那么加法门的输出就会减小，这反过来又会使乘法门的输出增加。

因此，反向传播可以被认为是门单元之间（通过梯度信号）相互通信，以此表达它们希望其输出增加还是减少（以及这种意愿有多强烈），从而使最终的输出值更高。

模块化：Sigmoid 示例

我们上面介绍的门单元相对来说是任意的。任何类型的可微函数都可以充当门单元，并且只要方便，我们可以将多个门组合成一个门，或者将一个函数分解为多个门。让我们看另一个说明这一点的表达式：

$$f(w,x) = \frac{1}{1+e^{-(w_0x_0 + w_1x_1 + w_2)}}$$

正如我们在课程后面将看到的，该表达式描述了一个使用 Sigmoid 激活 (sigmoid activation) 函数的二维神经元（输入为 $x$，权重为 $w$）。但现在，让我们非常简单地将其视为一个从输入 $w,x$ 到单个数字的函数。该函数由多个门组成。除了上面已经描述的那些（加法、乘法、最大值）之外，还有四个：

$$f(x) = \frac{1}{x} \rightarrow \frac{df}{dx} = -1/x^2$$

$$f_c(x) = c + x \rightarrow \frac{df}{dx} = 1$$

$$f(x) = e^x \rightarrow \frac{df}{dx} = e^x$$

$$f_a(x) = ax \rightarrow \frac{df}{dx} = a$$

其中函数 $f_c, f_a$ 分别将输入平移常数 $c$ 和缩放常数 $a$。这在技术上是加法和乘法的特例，但我们将它们作为（新的）一元门引入这里，因为我们不需要常数 $c, a$ 的梯度。整个电路如下图所示：

这是一个具有 Sigmoid 激活函数的二维神经元的示例电路。输入是 $[x_0, x_1]$，神经元的（可学习）权重是 $[w_0, w_1, w_2]$。正如我们在后面将看到的，神经元计算其输入与权重的点积，然后其激活值被 sigmoid 函数柔和地“挤压”到 0 到 1 的范围内。

在上面的例子中，我们看到了一长串的函数应用，它们对 $w,x$ 之间的点积结果进行操作。这些操作实现的函数称为 **Sigmoid 函数 $\sigma(x)$**。事实证明，sigmoid 函数相对于其输入的导数在经过推导后（利用在分子中加 1 减 1 这一有趣的技巧）会简化得非常漂亮：

$$\sigma(x) = \frac{1}{1+e^{-x}} $$

$$\rightarrow \quad \frac{d\sigma(x)}{dx} = \frac{e^{-x}}{(1+e^{-x})^2} = \left( \frac{1+e^{-x}-1}{1+e^{-x}} \right) \left( \frac{1}{1+e^{-x}} \right) = (1-\sigma(x))\sigma(x)$$

如我们所见，梯度简化后变得非常简单。例如，sigmoid 表达式在前向传播过程中接收输入 1.0 并计算输出 0.73。上面的推导表明，局部梯度将简单地是 $(1 - 0.73) \times 0.73 \approx 0.2$，正如电路之前计算的那样（见上图），只是这种方式将通过单个、简单且高效的表达式完成（并且数值问题更少）。因此，在任何实际应用中，将这些操作分组到单个门中是非常有用的。让我们看看这个神经元的反向传播代码：

加法门 (add gate) 总是接收其输出位置的梯度，并将其均等地分发给它的所有输入，无论前向传播时的输入值是多少。这源于加法运算的局部梯度简单地为 $+1.0$，因此所有输入上的梯度将精确等于输出上的梯度，因为它们乘以了 $1.0$（即保持不变）。在上面的示例电路中，请注意加法门将 $2.00$ 的梯度路由到了它的两个输入端，均等且未改变。

最大值门 (max gate) 对梯度进行路由。与加法门将梯度原样分发给所有输入不同，最大值门将梯度（原样）分配给它的恰好一个输入（即在前向传播期间具有最高值的那个输入）。这是因为最大值门的局部梯度对于最大值是 $1.0$，而对于所有其他值是 $0.0$。在上面的示例电路中，最大值运算将 $2.00$ 的梯度路由到了 $z$ 变量，因为它的值比 $w$ 高，而 $w$ 上的梯度保持为零。

乘法门 (multiply gate) 稍微没那么容易解释。它的局部梯度是输入值（只不过是交换过的），并且这会在链式法则过程中乘以其输出上的梯度。在上面的例子中，$x$ 上的梯度是 $-8.00$，即 $-4.00 \times 2.00$。

非直观的影响及其后果。注意，如果乘法门的一个输入非常小而另一个非常大，那么乘法门会做一些略微反直觉的事情：它会将一个相对巨大的梯度分配给小的输入，而将一个微小的梯度分配给大的输入。注意，在线性分类器中，权重与输入进行点积 $w^T x_i$（相乘），这意味着数据的尺度对权重的梯度幅度有影响。例如，如果你在预处理期间将所有输入数据样本 $x_i$ 乘以 $1000$，那么权重上的梯度将变大 $1000$ 倍，你就必须通过降低同样倍率的学习率来补偿。这就是为什么预处理非常重要，有时这种重要性体现在微妙的地方！对梯度如何流动有直观的理解可以帮助你调试其中一些情况。

总结

我们已经建立了关于梯度的直观理解：它们意味着什么，它们如何在电路中向后流动，以及它们如何“沟通”电路的哪一部分应该增加或减少，以及以多大的力度来使最终输出更高。

我们讨论了分阶段计算 (staged computation) 对于反向传播实际实现的重要性。你总是希望将函数分解为可以轻松推导局部梯度的模块，然后使用链式法则将它们链接起来。至关重要的是，你几乎不需要在纸上写出这些完整的表达式并对其进行符号微分，因为你永远不需要输入变量梯度的显式数学方程。因此，将表达式分解为多个阶段，以便你可以独立地对每个阶段进行微分（这些阶段可以是矩阵向量乘法、最大值操作或求和操作等），然后一步一步地通过变量进行反向传播。

在下一节中，我们将开始定义神经网络，反向传播将允许我们有效地计算损失函数相对于其参数的梯度。换句话说，我们现在已经准备好训练神经网络了，本课程概念上最困难的部分已经过去了！卷积神经网络 (ConvNets) 将指日可待。
