Image classification

本笔记主要讨论了图像分类问题，图像分类任务是指为输入的图片分配一个来自预先确定好的类别集合的标签。这是CV领域最基础也是用处最广泛的任务。

example

如下图所示，一张猫的照片作为输入图片，经过图片分类模型处理，得到了四个分布标签 {猫、狗、猪、马}（注意这里不要嘲笑任务的简单，当你训练的模型输出猪的时候感觉就在嘲讽了）

对于计算机来说，图像被表示为一个包含大量数字的三维数组。在这个例子中，猫的图像宽 248 像素，高 400 像素，并且有三个颜色通道 Red, Green, Blue（简写为 RGB）。因此，该图像由 248 x 400 x 3 个数字组成，总共是 297,600 个数字。每个数字是一个介于 0（黑色）到 255（白色）之间的整数。我们的任务是将这数以万计的数字转化为一个单一的标签，例如“猫”。

（如果你没有学过RGB的相关内容，实际上你只用知道所有的图片都是由三层堆叠而成的即可）

图像分类的任务是根据给定的图像预测一个单一标签（或如此处所示的标签分布，以表示我们的置信度）。图像由宽度 x 高度 x 3 的整数数组成，这些整数的取值范围是 0 到 255。这里的 3 代表了三个颜色通道：红、绿、蓝。

challenge

由于识别视觉概念（例如猫）对于人类来说相对简单，因此值得从计算机视觉算法的角度考虑其涉及的挑战。在下面列出（不完全）的挑战时，请记住图像的原始表示是一个亮度值的三维数组：

  • 视角变化。一个物体的单个实例可以以多种方式相对于相机进行取向。

  • 尺度变化。视觉类别通常在实际世界中的大小上存在变化，猫当然有很大还有很小的（而不仅仅是图像中的范围）。
  • 形变。许多感兴趣的对象并不是刚体，可以在极端情况下发生形变。
  • 遮挡。感兴趣的对象可能会被遮挡。有时仅有一小部分物体（甚至只有几个像素）可见。
  • 光照条件。光照效果在像素层面影响显著。
  • 背景杂乱。感兴趣的对象可能与其环境融合，使其难以识别。
  • 类内变化。感兴趣的类别通常可以相对广泛，例如椅子。这些物体有许多不同的类型，每种都有其独特的外观。

    一个好的图像分类模型必须对所有这些变化的交叉组合具有不变性，同时又能对类间变化保持敏感。

The image classification pipeline.

图像分类的流程。我们已经看到，图像分类的任务是将表示单张图像的像素数组分配一个标签。我们的完整流程可以形式化为以下步骤：

  • 输入：我们的输入包含一组 N 张图像，每张图像被标记为 K 个不同类别中的一个。我们将这些数据称为训练集。
  • 学习：我们的任务是利用训练集来学习每个类别的特征。我们称这一步为训练分类器，或学习模型。
  • 评估：最后，我们通过让分类器对一组它以前从未见过的新图像预测标签来评估其分类质量。然后我们将这些图像的真实标签与分类器预测的标签进行比较。直观来说，我们希望分类器的预测结果与真实答案（我们称之为 ground truth）有很多匹配的地方。

Nearest Neighbor Classifier

作为我们的第一种方法，我们将开发一种称为最近邻分类器（Nearest Neighbor Classifier）的分类器。这种分类器与卷积神经网络无关，实际上在实践中很少使用，但它将帮助我们了解图像分类问题的基本处理方法。

示例图像分类数据集：CIFAR-10。一个流行的玩具图像分类数据集是 CIFAR-10 数据集。该数据集包含 60,000 张尺寸为 32 像素高（32 * 32）的小图像。每张图像被标记为 10 个类别中的一个（例如“飞机、汽车、鸟等”）。这 60,000 张图像被划分为一个包含 50,000 张图像的训练集和一个包含 10,000 张图像的测试集。在下面的图像中，你可以看到来自每个类别中的 10 张随机示例图像：

L2的距离更换

请注意，我在上面包含了 np.sqrt 调用，但在实际的最近邻应用中，我们可以省略平方根运算，因为平方根是一个单调函数。也就是说，它会缩放距离的绝对大小，但保持顺序不变，因此有或没有平方根的最近邻结果是相同的。如果你在 CIFAR-10 数据集上使用这个距离运行最近邻分类器，你会得到 35.4%的准确率（略低于我们 L1 距离的结果）。

L1 与 L2。考虑这两种度量之间的差异是很有趣的。特别是，当比较两个向量之间的差异时，L2 距离比 L1 距离更加苛刻。也就是说，L2 距离更倾向于多个中等程度的不一致，而不是一个大的不一致。L1 和 L2 距离（或者等价地说，一对图像之间差异的 L1/L2 范数）是 p 范数最常见的特殊情形。

k - Nearest Neighbor Classifier

k邻近分类器的思想和最邻近分类器的思想类似

你可能已经注意到，当我们希望进行预测时，仅仅使用最近邻图像的标签是不够实际的。事实上，几乎总是可以通过使用所谓的 k 近邻分类器来获得更好的效果。其想法非常简单：我们不是在训练集中寻找单个最近的图像，而是寻找最接近的 k 个图像，并让它们对测试图像的标签进行投票。

特别是，当 k=1 时，我们得到的就是最近邻分类器。直观上，较大的 k 值会对分类器产生平滑效果，使其对异常值更具强健性：

上图中我们可以看到，nn最邻近分类器的表现一般，异常数据点可能会创建一些小的、可能错误的预测区域，但是5-nn分类器会平滑掉这些 irregularities (不规则性) 。可能在测试数据上具有更好的泛化能力（未显示），因为其对于边界的划分更加的完善。
另外请注意，在 5 最近邻图像中灰色区域是由最近邻投票中的平局引起的（例如，两个最近邻是红色，接下来的两个是蓝色，最后一个则是绿色）。

Validation sets for Hyperparameter tuning

*验证集用于超参数调优

k 近邻分类器需要设置 k 的值。但哪个数值效果最好呢？此外，我们还看到可以使用许多不同的距离函数，例如 L1 范数、L2 范数，还有许多我们甚至没有考虑的选择（例如点积）。（点积是向量积，有余弦相似度和点积相似度两种，余弦相似度用于nlp领域更多）这些选择被称为超参数，它们在许多从数据中学习的机器学习算法设计中经常出现。通常并不明显应该选择什么样的值或设置。

你可能会被诱惑去尝试很多不同的值，看看哪个效果最好。这是一个不错的主意，我们确实会这么做，但必须非常谨慎。特别是，我们不能用测试集来调整超参数。
每次你设计机器学习算法时，都应该把测试集视为一种非常宝贵的资源，理想情况下直到最后时刻才使用它。
否则，真实存在的危险是，你可能会调整超参数使其在测试集上表现良好，但如果你部署模型，可能会看到显著下降的性能。
在实践中，我们会说你对测试集过拟合了。另一种看法是，如果你在测试集上调整超参数，实际上就是在用测试集作为训练集，因此你在测试集上得到的性能会过于乐观，与实际部署时观察到的性能不符。 但如果你只在最后使用测试集一次，它仍然是衡量分类器泛化能力的一个很好的替代指标（我们将在课程后面看到更多关于泛化能力的讨论）。

你用测试集来调参的话，我只能说你是个外行。

*Evaluate on the test set only a single time, at the very end.

幸运的是，有一种正确的方法来调整超参数，而且完全不会使用测试集。这个想法是将我们的训练集分成两个部分：一个稍小的训练集，以及我们称之为验证集的部分。以 CIFAR-10 为例，我们可以用其中的 49,000 张训练图像进行训练，剩下的 1,000 张作为验证集。这个验证集本质上被当作一个假的测试集来调整超参数。

在完成此过程后，我们可以绘制出一个图表，显示哪些 k 值效果最好。然后我们会保留这个值，并在实际的测试集上进行一次评估。

Split your training set into training set and a validation set. Use validation set to tune all hyperparameters. At the end run a single time on the test set and report performance.

交叉验证

交叉验证。在训练数据量（以及因此也验证数据量）较小的情况下，人们有时会使用一种更复杂的超参数调优技术，称为交叉验证。以我们之前的例子来看，想法是通过在不同的验证集上进行迭代，并对这些验证集上的性能进行平均，从而获得更准确且更少噪声的评估结果。例如，在 5 折交叉验证中，我们将训练数据分成 5 个相等的折叠（folds），用其中 4 个进行训练，1 个进行验证。然后我们依次将每个折叠作为验证集，评估性能，最后将不同折叠的性能结果进行平均。

5 折交叉验证的一个示例运行情况，参数为 k。对于每个 k 值，我们使用 4 折进行训练，并在第 5 折上进行评估。因此，对于每个 k 值，我们会在验证折上得到 5 个准确率（准确率作为 y 轴，每个结果对应一个点）。
趋势线是通过每个 k 值的平均结果绘制的，误差条表示标准差。请注意，在这种情况下，交叉验证表明 k 约为 7 时在该数据集上表现最好（对应于图中的峰值）。如果我们使用超过 5 折的交叉验证，可能会看到一条更平滑（即噪声更少）的曲线。

实践中

实际上，人们更倾向于避免交叉验证，而采用单一的验证集分割，因为交叉验证可能会计算量很大。人们通常使用的分割方法是将训练数据的 50%-90%用于训练，其余部分用于验证。然而，这取决于多个因素：例如，如果超参数的数量很大，你可能更倾向于使用更大的验证集分割。如果验证集中的样本数量较少（可能只有几百个左右），则使用交叉验证更安全。在实践中，常见的交叉验证折数有 3 折、5 折或 10 折交叉验证。

常见数据划分。提供了一个训练集和测试集。训练集被划分为若干折（例如这里的 5 折）。其中 1-4 折作为训练集。一折（例如这里的第 5 折，用黄色表示）被作为验证集，用于调整超参数。交叉验证进一步地，会遍历选择哪一折作为验证集，分别从 1 到 5 进行。这被称为 5 折交叉验证。最后，当模型训练完成并且所有最佳超参数都确定后，模型会在测试数据（红色）上进行一次评估。

Pros and Cons of Nearest Neighbor classifier.

值得考虑最近邻分类器的一些优缺点。显然，其中一个优点是它非常容易实现和理解。此外，该分类器训练时间几乎为零，因为只需要存储并可能对训练数据进行索引。然而，我们在测试时却要付出计算代价，因为对一个测试样本进行分类需要与每一个训练样本进行比较。这与实际情况相反，因为在实践中我们通常更关注测试时的效率，而不是训练时的效率。事实上，我们之后将要开发的深度神经网络将这种权衡推向了另一个极端：它们训练成本很高，但一旦训练完成，对新的测试样本进行分类就非常高效。这种运行方式在实践中更加可取。

此外，最近邻分类器的计算复杂度是一个活跃的研究领域，存在多种近似最近邻（ANN）算法和库，可以加速数据集中最近邻的查找（例如 FLANN）。这些算法允许在检索过程中权衡最近邻查找的正确性与空间/时间复杂度，通常依赖于一个预处理/索引阶段，包括构建 kdtree 或运行 k-means 算法。

最近邻分类器在某些情况下（尤其是数据是低维的时候）可能是一个不错的选择，但在实际的图像分类设置中很少适用。一个问题在于图像通常是高维的对象（即它们通常包含很多像素），而在高维空间中距离的计算可能会有很大差异。下图说明了我们上面开发的基于像素的 L2 相似度与感知相似度之间的区别：

总结

  • We introduced the problem of Image Classification, in which we are given a set of images that are all labeled with a single category. We are then asked to predict these categories for a novel set of test images and measure the accuracy of the predictions.
    我们介绍了图像分类的问题，其中我们被提供一组全部标记有单一类别的图像。然后我们需要对一组新的测试图像进行预测，并衡量预测的准确性。
  • We introduced a simple classifier called the Nearest Neighbor classifier. We saw that there are multiple hyper-parameters (such as value of k, or the type of distance used to compare examples) that are associated with this classifier and that there was no obvious way of choosing them.
    我们介绍了一个简单的分类器，称为最近邻分类器。我们看到，这个分类器与多个超参数相关（例如 k 值或用于比较示例的距离类型），并且没有明显的方法来选择这些参数。
  • We saw that the correct way to set these hyperparameters is to split your training data into two: a training set and a fake test set, which we call validation set. We try different hyperparameter values and keep the values that lead to the best performance on the validation set.
    我们了解到，正确设置这些超参数的方法是将训练数据分成两部分：训练集和一个称为验证集的虚拟测试集。我们尝试不同的超参数值，并保留在验证集上表现最好的参数值。
  • If the lack of training data is a concern, we discussed a procedure called cross-validation, which can help reduce noise in estimating which hyperparameters work best.
    如果训练数据不足是一个问题，我们讨论了一种称为交叉验证的程序，它可以帮助减少在估计哪些超参数效果最佳时的噪声。
  • Once the best hyperparameters are found, we fix them and perform a single evaluation on the actual test set.
    一旦找到最佳的超参数，我们将其固定，并在实际的测试集上进行一次评估。
  • We saw that Nearest Neighbor can get us about 40% accuracy on CIFAR-10. It is simple to implement but requires us to store the entire training set and it is expensive to evaluate on a test image.
    我们看到，最近邻方法在 CIFAR-10 数据集上可以达到大约 40%的准确率。它易于实现，但需要我们存储整个训练集，并且在测试图像上进行评估的代价较高。
  • Finally, we saw that the use of L1 or L2 distances on raw pixel values is not adequate since the distances correlate more strongly with backgrounds and color distributions of images than with their semantic content.
    最后，我们看到使用原始像素值的 L1 或 L2 距离并不充分，因为这些距离更强烈地与图像的背景和颜色分布相关，而不是其语义内容。
