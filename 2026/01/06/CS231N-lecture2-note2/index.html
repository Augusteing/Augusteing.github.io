linear classification

在上一节中我们介绍了图像分类问题，即从固定的类别集合中为图像分配一个单一标签的任务。此外，我们还描述了 k-近邻（kNN）分类器，它通过将图像与训练集中的（标注过的）图像进行比较来对图像进行分类。如我们所见，kNN 存在一些缺点：

  • 分类器必须记住所有的训练数据，并将其存储以便将来与测试数据进行比较。这在空间上是低效的，因为数据集的大小可能轻松达到几十 GB。
  • 对测试图像进行分类的成本很高，因为它需要与所有训练图像进行比较。（算法效率低下）

概述

概述。我们现在将开发一种更强大的图像分类方法，最终自然地将其扩展到整个神经网络和卷积神经网络。该方法将包含两个主要组成部分：一个得分函数，它将原始数据映射到类别得分；以及一个损失函数，它量化预测得分与真实标签之间的匹配程度。我们将把这视为一个优化问题，在该问题中，我们将通过最小化损失函数来优化得分函数的参数。

parameterized mapping from images to label scores

linear classification score function

f(xi,W,b)=Wxi+b

在上述方程中，我们假设图像 xi 的所有像素都被展平为一个形状为[D x 1]的单列向量。矩阵 W（大小为[K x D]）和向量 b（大小为[K x 1]）是该函数的参数。在 CIFAR-10 中， xi 包含第 i 张图像的所有像素展平为一个[3072 x 1]的单列向量，W 是[10 x 3072]，b 是[10 x 1]，因此 3072 个数字进入该函数（原始像素值），10 个数字输出（类别得分）。W 中的参数通常被称为权重，而 b 被称为偏置向量，因为它影响输出得分，但不与实际数据 xi 相互作用。然而，你经常会听到人们将权重和参数这两个词混用。

这几点请你注意：（如果你的线性代数不太好。请去补习）

  • 首先，注意单次矩阵乘法 Wxi 实际上是在并行地评估 10 个独立的分类器（每个类别一个），其中每个分类器对应 W 中的一行。
  • 请注意，我们还将输入数据 (xi,yi) 视为已知且固定的，但我们能够控制参数 W,b 的设置。我们的目标是将这些参数设置为使得计算出的得分在整个训练集上与真实标签相匹配。我们将更详细地讨论如何实现这一点，但直观上，我们希望正确的类别得分高于错误类别的得分。
  • 这种方法的一个优势是，训练数据用于学习参数 W,b，但一旦学习完成，我们可以丢弃整个训练集，只保留学习到的参数。这是因为新的测试图像可以简单地通过该函数进行前向传播，并基于计算出的得分进行分类。
  • 最后，需要注意的是，对测试图像进行分类仅涉及一次矩阵乘法和加法，这比将测试图像与所有训练图像进行比较要快得多。

Interpreting a linear classifier

请注意，一个线性分类器将一个类的得分计算为该类所有像素值在三个颜色通道上的加权和。根据我们为这些权重设置的具体值，该函数有能力喜欢或不喜欢（根据每个权重的符号）图像中某些位置的特定颜色。例如，你可以想象，如果图像的侧面有很多蓝色（这可能对应于水），那么“船”这个类可能更有可能被识别。你可能会预期，“船”分类器在蓝色通道上会有大量的正权重（蓝色的存在会增加船的得分），而在红色/绿色通道上会有负权重（红色或绿色的存在会降低船的得分）。

将图像映射到类别得分的一个例子。为了便于可视化，我们假设图像只有 4 个像素（4 个单色像素，在这个例子中为了简洁我们不考虑颜色通道），并且有 3 个类别（红色代表猫，绿色代表狗，蓝色代表船）。（说明：这里的颜色仅表示 3 个类别，并与 RGB 通道无关。）我们将图像像素拉伸成一列，并通过矩阵乘法来获得每个类别的得分。请注意，这组特定的权重 W 并不好：权重将我们的猫图像分配了一个非常低的猫得分。特别是，这组权重似乎确信它正在看一只狗。

Analogy of images as high-dimensional points.

由于图像被拉伸为高维的列向量，我们可以将每张图像解释为空间中的一个点（例如，CIFAR-10 中的每张图像都是 32x32x3 像素的 3072 维空间中的一个点）。类似地，整个数据集可以看作是一组（带标签的）点。

由于我们定义了每个类别的得分作为所有图像像素的加权和，每个类别的得分都是该空间上的线性函数。我们无法可视化 3072 维的空间，但如果我们将所有这些维度压缩到只有两个维度，那么我们可以尝试可视化分类器可能在做什么：

图像空间的表示，其中每张图像都是一个点，三个分类器被可视化。以汽车分类器（红色）为例，红色的线表示在空间中所有对汽车类别得分为零的点。红色箭头表示得分增加的方向，因此红色线右侧的所有点得分都是正的（并且线性增加），而左侧的所有点得分都是负的（并且线性减少）。

或许你对此处的数学逻辑不太理解，如果一个分类器只有两个数 w1、w2，分别对应两个像素点x、y。那么对于任意的x和y存在这样一条直线：w1 x + w2y = 0

geometry interpretation

如上所述， W 的每一行都是一个类别的分类器。这些数值的几何解释是，当我们改变 W 的某一行时，像素空间中的对应直线会在不同的方向上旋转。另一方面，偏置项 b 允许我们的分类器平移这些直线。特别地，请注意，如果没有偏置项，无论权重如何，将 xi=0（请注意这里是0向量而不是标量0） 代入都会得到零分，因此所有直线都会被强制通过原点。

template interpretation

另一种对权重 W 的解释是， W 中的每一行对应一个类别的一个模板（有时也称为原型）。每个类别的得分是通过依次用内积（或点积）将每个模板与图像进行比较，找到最“匹配”的模板来获得的。用这种术语来说，线性分类器是在进行模板匹配，其中模板是通过学习得到的。另一种思考方式是，我们仍然在进行最近邻分类，只不过不是使用成千上万的训练图像，而是每个类别只使用一张图像（尽管我们会学习它，它不一定要是训练集中的某一张图像），并且使用（负的）内积作为距离，而不是 L1 或 L2 距离。

略过一些内容：训练结束后 CIFAR-10 的示例学习到的权重。请注意，例如，船的模板包含大量蓝色像素，这是符合预期的。因此，当该模板与海洋中的船的图像进行内积匹配时，会得到一个高分。

此外，请注意马的模板似乎包含了一匹双头马，这是由于数据集中同时存在左看和右看的马。线性分类器将数据中的这两种马的模式合并为一个模板。同样，汽车分类器似乎也将多种模式合并为一个模板，该模板需要从各个角度和各种颜色中识别汽车。特别是，这个模板最终呈现为红色，这表明 CIFAR-10 数据集中红色汽车的数量比其他颜色都多。线性分类器无法很好地处理不同颜色的汽车，但正如我们后面将看到的，神经网络将允许我们完成这项任务。展望一下，神经网络将在其隐藏层中发展出中间神经元，以检测特定类型的汽车（例如绿色左向汽车、蓝色正向汽车等），而下一层的神经元则可以通过对各个汽车检测器的加权求和，将这些信息组合成更准确的汽车得分。

实际上线性分类器存在局限

bias trick

在继续之前，我们想提到一个常用的简化技巧，即将两个参数 W,b 表示为一个。回想一下，我们定义的得分函数为：

f(xi,W,b)=Wxi+b

随着我们逐步学习材料，单独跟踪两个参数集（偏置 b 和权重 W ）会有些繁琐。一个常用的技巧是将这两个参数集合并到一个矩阵中，通过在向量 xi 中增加一个额外的维度，该维度始终保存常数 1 ——一个默认值。有了这个额外的维度，新的得分函数将简化为一次矩阵乘法：

f(xi,W)=Wxi

在我们的 CIFAR-10 例子中， xi 现在是 [3073 x 1] 而不是 [3072 x 1] -（额外的维度保存的是常数 1），而 W 现在是 [10 x 3073] 而不是 [10 x 3072]。 W 的额外列现在对应的是偏置 b 。一个示意图或许有助于澄清：

偏差技巧的示意图。进行矩阵乘法然后加上一个偏差向量（左）等同于将所有输入向量添加一个常数为 1 的偏差维度，并将权重矩阵扩展为一个包含偏差列的矩阵（右）。因此，如果我们预处理数据时在所有向量末尾添加 1，我们只需要学习一个权重矩阵，而不需要两个分别存储权重和偏差的矩阵。

Image data preprocessing.

图像数据预处理。作为快速说明，在上面的例子中我们使用了原始像素值（范围为[0…255]）。在机器学习中，对输入特征进行归一化是一个非常常见的做法（在图像的情况下，每个像素都被视为一个特征）。特别是，对数据进行中心化处理（即从每个特征中减去均值）是非常重要的。在图像的情况下，这对应于计算训练图像的均值图像，并将其从每张图像中减去，以得到像素值范围大约在[-127 … 127]的图像。进一步常见的预处理步骤是将每个输入特征缩放，使其值范围在[-1, 1]之间。

其中，零均值中心化被认为更为重要，但其合理性我们将在理解梯度下降的动态过程之后才能得到充分的解释。

loss function

在上一节中，我们定义了一个从像素值到类别得分的函数，该函数由一组权重 W 参数化。此外，我们还看到，我们无法控制数据 (xi,yi) （它是固定且给定的），但我们能够控制这些权重，并希望设置它们使得预测的类别得分与训练数据中的真实标签保持一致。

例如，回到我们之前提到的猫的示例图像及其对“cat”、“dog”和“ship”类别的得分，我们发现该示例中的特定权重集并不十分优秀：我们输入了描绘猫的像素，但“cat”类的得分却非常低（-96.8），与其他类别（“dog”得分 437.9，“ship”得分 61.95）相比。我们将使用损失函数（有时也称为成本函数或目标函数）来衡量我们对这种结果的不满程度。直观来说，如果我们对训练数据分类效果不好，损失就会很高；如果我们分类效果很好，损失就会很低。

Multiclass Support Vector Machine loss

有几种方式可以定义损失函数的细节。作为第一个例子，我们将开发一个常用的损失函数，称为 SVM 损失。SVM 损失的设置使得 SVM“希望”每张图像的正确类别得分比所有错误类别高一个固定的边界 Δ 。请注意，有时将损失函数拟人化是有帮助的，如上所述：SVM“希望”某种结果，意味着这种结果会带来更低的损失（这是好的）。

The loss function quantifies our unhappiness with predictions on the training set

多类支持向量机“希望”正确类别的分数比所有其他分数至少高出 delta。如果任何类别的分数在红色区域内（或更高），则会产生累积损失。否则损失将为零。我们的目标将是找到能够同时满足训练数据中所有样本的约束条件的权重，并使总损失尽可能低。

regularization

我们上面提出的损失函数存在一个缺陷。假设我们有一个数据集和一组参数，这些参数能够正确分类每个样本（即所有得分都满足所有间隔条件，并且对于所有 i， Li=0 ）。问题在于，这组参数不一定是唯一的：可能存在许多相似的参数也能正确分类样本。一个简单的方法是，如果某些参数能正确分类所有样本（即每个样本的损失为零），那么这些参数的任何倍数 λW （其中 λ>1 ）也会给出零损失，因为这种变换会均匀地拉伸所有得分的大小，从而也拉伸了它们的绝对差值。例如，如果正确类别和最近错误类别之间的得分差是 15，那么将的所有元素乘以 2 会使新的差值变为 30。

除了我们上面提供的动机之外，包含正则化惩罚还有许多理想特性，其中许多我们将在后面的章节中再次讨论。例如，事实证明包含 L2 惩罚会导致 SVM 中吸引人的最大间隔特性（如果您感兴趣，可以参考 CS229 课程笔记了解详细信息）。

最吸引人的特性是惩罚大的权重（这里的意思是，会让W中不会出现太大的值）往往会提高泛化能力，因为这意味着没有任何一个输入维度能够单独对分数产生很大的影响。例如，假设我们有一个输入向量 x=[1,1,1,1] 和两个权重向量 w1=[1,0,0,0] 、 w2=[0.25,0.25,0.25,0.25] 。那么 wT1x=wT2x=1 ，所以这两个权重向量导致相同的点积，但 w1 的 L2 惩罚是 1.0，而 w2 的 L2 惩罚只有 0.25。因此，根据 L2 惩罚，权重向量 w2 会被优先选择，因为它实现了更低的正则化损失。直观上，这是因为 w2 中的权重更小且更分散。由于 L2 惩罚倾向于更小、更分散的权重向量，最终的分类器被鼓励考虑所有输入维度以少量，而不是少数几个输入维度且非常强烈。正如我们将在课程后面看到的，这种效果可以提高分类器在测试图像上的泛化性能，并导致更少。

请注意，偏差（b）的影响并不相同，因为与权重不同，它们不控制输入维度的影响力强度。因此，通常只正则化权重 W 但不正则化偏差 b 。然而，在实践中，这通常被证明几乎没有影响。最后，请注意，由于正则化惩罚，我们永远无法在所有示例上实现精确的 0.0 损失，因为这种情况只有在 W=0 的病态设置下才可能发生。

Practical Considerations

请注意，我们忽略了超参数 Δ 及其设置。它应该设置为多少，我们是否需要进行交叉验证？事实证明，这个超参数在所有情况下都可以安全地设置为 Δ=1.0 。超参数 Δ 和 λ 看起来像是两个不同的超参数，但实际上它们都控制着同一个权衡：目标函数中数据损失和正则化损失之间的权衡。理解这个问题的关键在于权重的幅度（翻译成比例或者更好） W 对分数（以及它们的差异）有直接影响：当我们缩小 W 内的所有值时，分数差异会变得较低，而当我们放大权重时，分数差异会全部变得较高。因此，分数之间的边际的确切值（例如 Δ=1 ，或 Δ=100 ）在某种程度上是无意义的，因为权重可以任意地缩小或放大差异。

因此，唯一真正的权衡是我们允许权重增长到多大（通过正则化强度 λ ）。

命名上的问题

可能令人困惑的命名惯例。准确地说，SVM 分类器使用的是 hinge loss，有时也称为 max-margin loss。Softmax 分类器使用的是 cross-entropy loss。Softmax 分类器得名于 softmax 函数，该函数用于将原始类别分数压缩成归一化的正值，这些值之和为 1，以便可以应用交叉熵损失。特别要注意的是，从技术上讲，谈论“softmax loss”没有意义，因为 softmax 只是一个压缩函数，但它是一个相对常用的简称。

SVM 和 softMax的区别

SVM 和 Softmax 分类器在单个数据点上的差异示例。在两种情况下，我们都计算相同的得分向量 f（例如，在本节中通过矩阵乘法计算）。差异在于对 f 中得分的解释：SVM 将这些得分解释为类别得分，其损失函数鼓励正确类别（蓝色类别 2）的得分比其他类别得分高出一个间隔。Softmax 分类器则将得分解释为每个类别的（未归一化）对数概率，然后鼓励正确类别的（归一化）对数概率较高（等效地，其负值较低）。此示例中，SVM 的最终损失为 1.58，Softmax 分类器的最终损失为 1.04（注意，这是使用自然对数计算的，不是以 2 或 10 为底的对数），但请注意，这些数字不可比较；它们仅在相同分类器和相同数据计算出的损失中才有意义。

与支持向量机（SVM）计算未经校准且难以解释的所有类别的分数不同，Softmax 分类器允许我们为所有标签计算“概率”。例如，对于一张图像，SVM 分类器可能会给出类别“猫”、“狗”和“船”的分数[12.5, 0.6, -23.0]。而 Softmax 分类器则可以计算这三个标签的概率为[0.9, 0.09, 0.01]，这使你能够解释它在每个类别中的置信度。然而，我们之所以将“概率”一词加引号，是因为这些概率的峰值或弥散程度直接取决于正则化强度 λ ——这是你作为系统输入负责的。例如，假设某些三个类别的未归一化对数概率为[1, -2, 0]。Softmax 函数随后会计算：
