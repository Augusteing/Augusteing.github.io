一、NumPy 中“轴（axis）”的核心理解

在 NumPy 中，大多数聚合函数（如 sum、mean、split、concatenate）都依赖 axis 参数。axis 的本质含义是“沿着哪一个维度进行操作，哪一个维度被消去或被拼接”。

对于一个典型的训练数据矩阵 X_train，其形状通常为 (N, D)，其中 N 表示样本数，D 表示特征维度（如 CIFAR-10 中的 3072 个像素）。

  • axis=0：沿“样本维度”操作（对样本做聚合或拼接）

  • axis=1：沿“特征维度”操作（对每个样本的特征做聚合或拼接）

这是后续理解所有 NumPy 函数的前提。

二、np.sum：按维度求和的标准工具

np.sum 用于对数组元素求和，其行为由 axis 决定。

当对二维数组 X（形状 (N, D)）使用：

  • np.sum(X, axis=0)：得到长度为 D 的向量，表示 所有样本在每个特征维度上的总和

  • np.sum(X, axis=1)：得到长度为 N 的向量，表示 每个样本内部特征的总和

在 KNN 的距离计算中，axis=1 常用于计算 单个样本的平方范数，例如：

对每一行（一个样本）的所有特征平方后求和。

这是实现向量化 L2 距离公式的关键一步。

三、np.argsort：排序但返回索引

np.argsort 的作用是：

返回数组排序后元素在原数组中的索引顺序。

在 KNN 中，它是“找到最近邻”的核心函数。

典型用法是：

对某一个测试样本到所有训练样本的距离向量进行排序，取前 k 个索引。

此时，argsort 返回的索引用于从 y_train 中取出对应的标签，而不是用于取距离本身。

需要注意的是：

  • argsort 默认是升序排序

  • 对距离而言，升序意味着“最近的在前面”

四、np.argmax：最大值位置，而非最大值本身

np.argmax 返回的是 数组中最大值第一次出现的位置（索引），而不是最大值。

在 KNN 的投票阶段，常见模式是：

先统计每个标签出现的次数，再找出现次数最多的标签。

由于 np.unique(..., return_counts=True) 返回的 values 默认是 升序排列，因此：

  • 当多个标签出现次数相同（tie）时

  • np.argmax(counts) 会返回最小标签对应的位置

这 隐式满足了“平票选标签值较小者”的要求，但这是依赖 NumPy 行为的结果，而非显式逻辑。

五、np.unique：统计标签频率的标准方式

np.unique(arr, return_counts=True) 在 KNN 中非常常用，其作用是：

  • values：去重后的标签（自动排序）

  • counts：每个标签出现的次数

这是实现多数投票（majority vote）的标准 NumPy 写法，比手动 for 循环更清晰、也更高效。

六、广播（Broadcasting）：向量化实现的数学基础

NumPy 的广播机制允许不同形状的数组在 满足一定规则时自动扩展维度进行运算。

在无循环实现 L2 距离时，常见的公式是：

|x - y|² = |x|² + |y|² - 2x·y

在代码中体现为：

  • X_test_square：形状 (num_test,)

  • X_train_square：形状 (num_train,)

  • cross = X_test @ X_train.T：形状 (num_test, num_train)

当执行：

X_test_square[:, None] + X_train_square[None, :] - 2 * cross

NumPy 会自动广播，使一维数组扩展为二维矩阵，从而完成逐元素运算。

广播的核心原则是：

从右往左对齐维度，维度相等或其中一个为 1 才能广播。

七、np.concatenate：拼接数组的通用方法

np.concatenate 的作用是：

沿指定轴，将多个 NumPy 数组合并成一个更大的数组。

在 k-fold 交叉验证中，它是拼接训练集的核心函数。

典型场景是：

将除当前验证折以外的所有 fold 沿 axis=0 拼接成训练集。

必须注意：

  • 所有数组的维度数必须相同

  • 除拼接轴以外的维度必须完全一致

axis=0 表示拼样本，axis=1 表示拼特征。在交叉验证中，几乎永远使用 axis=0。

八、np.split 与 np.array_split：fold 切分的区别

np.split 用于将数组均分为若干块，但它有一个严格要求：

数组在该轴上的长度必须能被分块数整除。

如果不能整除，就会抛出：

ValueError: array split does not result in an equal division

相比之下，np.array_split 更灵活：

  • 允许不能整除

  • 会自动让前几个 fold 多一个样本

在实验与课程作业中，np.array_split 更安全、更推荐。

九、字典 + 列表：存储交叉验证结果的标准结构

在 k-fold 交叉验证中，通常使用如下结构：

key：k 的取值（邻居数） value：一个列表，存储该 k 在每一折上的准确率

正确的使用模式是：

  1. 先为每个 key 初始化一个空列表

  2. 在每一折中计算 accuracy

  3. 使用 append 加入列表

必须注意：

list.append() 的返回值是 None，不能写成赋值语句。

全连接神经网络

前向传播

这一部分只用单纯计算就好，需要指出的是 b 添加到结果的方式：我们将b复制 n 次然后加到最后的结果矩阵中。

反向传播

对于全连接网络，普遍的数学表达式为：

$$ out = XW + b $$

为了求反向传播的结果，我们使用链式法则：
$$ \frac {∂L} {∂b} = \frac{∂L} {∂out}\frac {∂out} {∂b}
$$
对于 W 和 X 的求导详情请见：lecture4 note 2 给出了很好的推导。
$$\boxed{\frac{\partial L}{\partial X} = \frac{\partial L}{\partial Y} W^T} \quad (24)$$

$$\boxed{\frac{\partial L}{\partial W} = X^T \frac{\partial L}{\partial Y}} \quad (25)$$
这里仅给出公式。

但这里要注意 b ，b是一个向量，但是作用于out的时候，我们把b加到了out的每一行中。

所以我们谈论b的梯度时，要考虑向量b中的单个元素对于out的作用，然后利用 $\frac {\partial L} {\partial out}$
求出该元素对于L的作用。

我们知道 b 通过加到 out 上的每一行来作用于out。所以，对于 $b$ 中的单个元素 $b_j$ ，对于 $out$ 进行求导，我们有：
$$\frac {\partial out} {\partial b_j} = \sum_i \frac {\partial out_{i,j}} {\partial b_j}
$$
其中我们不难知道：
$$ \frac {\partial out_{i,j}} {\partial b_j} = 1$$

那么实际上：
$$\frac {\partial out} {\partial b_j} = \sum_i \frac {\partial out_{i,j}} {\partial b_j} = N
$$
所以最终：
$$ \frac {\partial L} {\partial b} = \frac{∂L} {∂out} \frac{\partial out} {\partial b} = \sum_i^N out_i
$$

特征提取

For each image we will compute a Histogram of Oriented Gradients (HOG) as well as a color histogram using the hue channel in HSV color space. We form our final feature vector for each image by concatenating the HOG and color histogram feature vectors.
对于每张图像，我们将计算方向梯度直方图（HOG）以及使用 HSV 颜色空间中的色调通道计算颜色直方图。我们通过连接 HOG 和颜色直方图特征向量来形成每张图像的最终特征向量。

Roughly speaking, HOG should capture the texture of the image while ignoring color information, and the color histogram represents the color of the input image while ignoring texture. As a result, we expect that using both together ought to work better than using either alone. Verifying this assumption would be a good thing to try for your own interest.
大致来说，HOG 应该捕捉图像的纹理而忽略颜色信息，而颜色直方图则代表输入图像的颜色而忽略纹理。因此，我们期望结合使用两者应该比单独使用任何一种效果更好。验证这一假设是一个值得尝试的事情。

The hog_feature and color_histogram_hsv functions both operate on a single image and return a feature vector for that image. The extract_features function takes a set of images and a list of feature functions and evaluates each feature function on each image, storing the results in a matrix where each column is the concatenation of all feature vectors for a single image.
hog_feature 和 color_histogram_hsv 函数都作用于单张图像并返回该图像的特征向量。extract_features 函数接收一组图像和一组特征函数的列表，并在每张图像上评估每个特征函数，将结果存储在一个矩阵中，其中每一列是单张图像的所有特征向量的连接。

这段话的意思是，把“黑白素描”（HOG）和“调色板”（Color）结合起来，你就能得到一个既有形状又有颜色的完整描述。这样计算机分类（比如区分红苹果和绿苹果，或者红苹果和红球）的效果就会更好。

假设对于一张图片：

  • HOG 计算结果是一个长度为 3 的数组（举例）：[0.5, 0.1, 0.2]

  • Color 计算结果是一个长度为 2 的数组（举例）：[0.9, 0.8]

所谓的Concatenation（连接/拼接），就是直接把它们首尾相连，变成一个更长的数组：

  • 最终特征：[0.5, 0.1, 0.2, 0.9, 0.8] （长度变成了 3+2=5）

在代码中，这通常使用 numpy.hstack 或 numpy.concatenate 来实现。

这段话最后描述了数据是如何存储的。

假设你有 N 张图片（比如 N=100 张），每张图片提取出的最终特征长度是 D（比如 D=144）。

extract_features 函数的逻辑如下：

  1. 它遍历这 100 张图片。

  2. 对第 1 张图，算出 HOG，算出 Color，拼起来，得到一个长长的列向量（Vector 1）。

  3. 对第 2 张图，重复上述步骤，得到 Vector 2。

  4. …

  5. 最后，它把这 100 个向量按列（Column）排排站，组成一个大矩阵。

最终矩阵的样子：

$$\begin{bmatrix} | & | & & | \ \text{图1特征} & \text{图2特征} & \dots & \text{图N特征} \ | & | & & | \end{bmatrix}$$

  • 矩阵的行数 (Rows) = 特征的总长度 (HOG长度 + Color长度)。

  • 矩阵的列数 (Columns) = 图片的数量 (N)。
