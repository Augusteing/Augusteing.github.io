CS231N assignment2：Batch Normalization

Batch Normalization

让深度网络更容易训练的一种方法是使用更复杂的优化程序，如 SGD+动量、RMSProp 或 Adam。另一种策略是改变网络的架构使其更容易训练。沿着这些思路的一种想法是批量归一化，由[1]在 2015 年提出。

要理解批量归一化的目标，首先需要认识到机器学习方法通常在输入数据由不相关的特征组成，而且均值为零、方差为一时表现更好。在训练神经网络时，我们可以在将数据输入网络之前对其进行预处理，以显式地去除其特征的相关性。这将确保网络的第一层看到的数据遵循良好的分布。然而，即使我们预处理了输入数据，网络更深层的激活值很可能也会相关，也不再具有零均值或单位方差，因为它们来自网络更早的层。更糟糕的是，在训练过程中，随着每一层权重的更新，网络每一层特征的分布都会发生变化。

（虽然我们可以把最初喂给网络的数据整理得很完美，但在神经网络内部，随着层数加深和权重的不断更新，数据分布会变得越来越混乱，这会让深层网络的训练变得非常困难。）

[1] 的作者假设深度神经网络中特征的分布偏移可能会使深度网络的训练更加困难。为了克服这个问题，他们建议在网络层中插入批量归一化层。在训练时，这种层使用一小批数据来估计每个特征的均值和标准差。然后使用这些估计的均值和标准差来对这批数据的特征进行居中和归一化。在训练过程中，会保留这些均值和标准差的运行平均值，在测试时使用这些运行平均值来对特征进行居中和归一化

这种归一化策略可能会降低网络的表示能力，因为对于某些层来说，特征不是零均值或单位方差有时可能是最优的。为此，批量归一化层为每个特征维度包含了可学习的偏移和缩放参数

[1] Sergey Ioffe 和 Christian Szegedy, “Batch Normalization: Accelerating Deep Network Training by Reducing Internal Covariate Shift”, ICML 2015.

任务一

任务一要求实现 batchnorm_forward 函数：

在训练期间，我们会根据小批量（minibatch）的统计数据来计算样本均值和（未校正的）样本方差，并将它们用于对输入数据进行归一化处理。同时在训练期间，我们还会对每个特征的均值和方差保留一个指数衰减的滑动平均值（running averages），这些滑动平均值将在测试阶段被用来对数据进行归一化。

在每一个时间步，我们都会使用基于动量（momentum）参数的指数衰减公式来更新均值和方差的滑动平均值：

running_mean = momentum * running_mean + (1 - momentum) * sample_mean
running_var = momentum * running_var + (1 - momentum) * sample_var

通常，我们将 momentum 设为 0.9. 所以我们更倾向于保留历史记忆。

请注意，原始的批量归一化（Batch Normalization）论文建议在测试阶段采用一种不同的做法：他们主张使用大量的训练图像来计算每个特征的样本均值和方差，而不是使用滑动平均值。在当前的实现中，我们选择使用滑动平均值，因为这样不需要在测试前增加额外的估计步骤；Torch7 框架中的批量归一化实现也同样使用了滑动平均值。

  • 有关于为什么测试/推理时不计算当前数据的均值和方差，而是用滑动平均值？
  • 当仅仅输入一张照片时，我们计算该批次每个特征的方差，会导致方差为0。这没有办法进行归一化操作。

批量归一化会把数据强行变成“均值为 0，方差为 1”的标准分布。而sigmoid在中心附近几乎就是直线，这意味着原本用来增加网络复杂度的非线性激活函数，退化成了简单的线性变换。

所以我们使用 gamma 和 beta 这两个神经网络学习的参数进行数值的变化和微调。$y = \gamma \times x_{normalized} + \beta$

实际上我们可以通过设置 $\gamma = samplemean^2$ ，$\beta = \mu$ 就可以将归一化的值复原为归一化之前的值。

任务二

现在在函数 batchnorm_backward 中实现批量归一化的反向传播。

其中的数学推导并不复杂：

为了简化推导，我们专注于某一个特定的特征通道（某一列）。假设 Batch Size 为 $N$，输入为向量 $x = [x_1, x_2, …, x_N]^T$。总损失函数记为 $L$。假设上游传回来的梯度为 $dy_i = \frac{\partial L}{\partial y_i}$（在代码中通常称为 dout）。

前向传播的四个步骤：

  1. 计算均值：$\mu = \frac{1}{N} \sum_{i=1}^N x_i$

  2. 计算方差：$\sigma^2 = \frac{1}{N} \sum_{i=1}^N (x_i - \mu)^2$

  3. 标准化：$x_{nor_i} = \frac{x_i - \mu}{\sqrt{\sigma^2 + \epsilon}}$

  4. 缩放与平移：$y_i = \gamma x_{nor_i} + \beta$

反向传播有：

1. 求 $\beta$ 的梯度 ($d\beta$)

$$y_i = \gamma x_{nor_i} + \beta \implies \frac{\partial y_i}{\partial \beta} = 1$$
$$d\beta = \frac{\partial L}{\partial \beta} = \sum_{i=1}^N \frac{\partial L}{\partial y_i} \cdot \frac{\partial y_i}{\partial \beta} = \sum_{i=1}^N dy_i$$

2. 求 $\gamma$ 的梯度 ($d\gamma$)

$$y_i = \gamma x_{nor_i} + \beta \implies \frac{\partial y_i}{\partial \gamma} = x_{nor_i}$$
$$d\gamma = \frac{\partial L}{\partial \gamma} = \sum_{i=1}^N \frac{\partial L}{\partial y_i} \cdot \frac{\partial y_i}{\partial \gamma} = \sum_{i=1}^N dy_i \cdot x_{nor_i}$$

3. 求中间变量 $x_{nor_i}$ 的局部梯度 ($dx_{nor_i}$)

为了后续推导方便，我们先求出梯度流到 $x_{nor_i}$ 时的值：

$$dx_{nor_i} = \frac{\partial L}{\partial x_{nor_i}} = \frac{\partial L}{\partial y_i} \cdot \frac{\partial y_i}{\partial x_{nor_i}} = dy_i \cdot \gamma$$

上述过程非常明显，所以不多赘述。

4. 求方差 $\sigma^2$ 的梯度 ($d\sigma^2$)

观察第 3 步公式：$x_{nor_i} = (x_i - \mu)(\sigma^2 + \epsilon)^{-\frac{1}{2}}$。

对其求 $\sigma^2$ 的偏导：

$$\frac{\partial x_{nor_i}}{\partial \sigma^2} = (x_i - \mu) \cdot \left(-\frac{1}{2}\right)(\sigma^2 + \epsilon)^{-\frac{3}{2}}$$

应用链式法则累加：

$$d\sigma^2 = \frac{\partial L}{\partial \sigma^2} = \sum_{i=1}^N dx_{nor_i} \cdot \frac{\partial x_{nor_i}}{\partial \sigma^2} = -\frac{1}{2}(\sigma^2 + \epsilon)^{-\frac{3}{2}} \sum_{i=1}^N dx_{nor_i} \cdot (x_i - \mu)$$

5. 求均值 $\mu$ 的梯度 ($d\mu$)

均值 $\mu$ 存在于两个地方：第 2 步的方差计算和第 3 步的标准化计算。但经过巧妙的数学抵消，方差分支带来的 $\mu$ 的梯度和为 0（上一轮对话中已证明）。因此只需考虑第 3 步直接相连的部分：

$$\frac{\partial x_{nor_i}}{\partial \mu} = \frac{-1}{\sqrt{\sigma^2 + \epsilon}}$$

$$d\mu = \frac{\partial L}{\partial \mu} = \sum_{i=1}^N dx_{nor_i} \cdot \frac{\partial x_{nor_i}}{\partial \mu} = \frac{-1}{\sqrt{\sigma^2 + \epsilon}} \sum_{i=1}^N dx_{nor_i}$$

现在我们注意单个输入 $x_i$。它的改变会通过三条路径影响最终的 Loss：

  1. 直接路径：$x_i \rightarrow x_{nor_i} \rightarrow L$

  2. 方差路径：$x_i \rightarrow \sigma^2 \rightarrow \text{所有 } x_{nor} \rightarrow L$

  3. 均值路径：$x_i \rightarrow \mu \rightarrow \text{所有 } x_{nor} \rightarrow L$

根据多变量微积分的全微分法则，我们将这三部分的偏导数相加：

$$dx_i = \frac{\partial L}{\partial x_i} = \underbrace{dx_{nor_i} \cdot \frac{\partial x_{nor_i}}{\partial x_i}}{\text{直接}} + \underbrace{d\sigma^2 \cdot \frac{\partial \sigma^2}{\partial x_i}}{\text{方差}} + \underbrace{d\mu \cdot \frac{\partial \mu}{\partial x_i}}_{\text{均值}}$$

我们分别计算三个局部的偏导：

  • 直接分支：$\frac{\partial x_{nor_i}}{\partial x_i} = \frac{1}{\sqrt{\sigma^2 + \epsilon}}$

  • 方差分支：$\frac{\partial \sigma^2}{\partial x_i} = \frac{2(x_i - \mu)}{N}$

  • 均值分支：$\frac{\partial \mu}{\partial x_i} = \frac{1}{N}$

将它们与第二阶段求出的 $d\sigma^2$ 和 $d\mu$ 代入合并：

$$dx_i = dx_{nor_i} \cdot \frac{1}{\sqrt{\sigma^2 + \epsilon}} + d\sigma^2 \cdot \frac{2(x_i - \mu)}{N} + d\mu \cdot \frac{1}{N}$$

直接使用上面的公式编程仍然繁琐。我们可以通过代换 $x_{nor_i} = \frac{x_i - \mu}{\sqrt{\sigma^2 + \epsilon}}$ 进行变换。

首先展开方差项（将 $x_i - \mu$ 替换为 $x_{nor_i} \sqrt{\sigma^2 + \epsilon}$）：

$$d\sigma^2 \cdot \frac{2(x_i - \mu)}{N} = \left( -\frac{1}{2(\sigma^2 + \epsilon)} \sum_{j=1}^N dx_{nor_j} \cdot x_{nor_j} \right) \cdot \frac{2 \cdot x_{nor_i}}{N}$$

$$= -\frac{x_{nor_i}}{N \sqrt{\sigma^2 + \epsilon}} \sum_{j=1}^N (dx_{nor_j} \cdot x_{nor_j})$$

接着展开均值项：

$$d\mu \cdot \frac{1}{N} = -\frac{1}{N \sqrt{\sigma^2 + \epsilon}} \sum_{j=1}^N dx_{nor_j}$$

将三项相加，并提出公因式 $\frac{1}{N \sqrt{\sigma^2 + \epsilon}}$，我们得到：

$$dx_i = \frac{1}{N \sqrt{\sigma^2 + \epsilon}} \left( N \cdot dx_{nor_i} - \sum_{j=1}^N dx_{nor_j} - x_{nor_i} \sum_{j=1}^N (dx_{nor_j} \cdot x_{nor_j}) \right)$$

任务4：层归一化

批归一化已被证明能够使网络更容易训练，但由于硬件限制导致输入批大小受限的复杂网络中，对批大小的依赖性使其不太实用。

为了缓解（批量归一化的）问题，人们提出了几种替代方案，其中之一就是层归一化 (Layer Normalization)。我们不再跨越批次 (Batch) 进行归一化，而是跨越特征 (Features) 进行归一化。换句话说，当使用层归一化时，每个单独的数据样本所对应的特征向量，是根据该向量内部所有元素的总和来进行归一化的。

https://www.google.com/url?q=https%3A%2F%2Farxiv.org%2Fpdf%2F1607.06450.pdf

特性 Batch Normalization (批量归一化) Layer Normalization (层归一化)
切割方向 **纵向切割 (按列)**：对同一个特征，计算所有样本的均值和方差。 **横向切割 (按行)**：对同一个样本，计算它所有特征的均值和方差。
受批大小影响? 极其严重。Batch Size 越小，统计误差越大。Batch Size 为 1 时直接崩溃。 完全无关。它只关心单个样本本身，哪怕每次只喂给网络 1 张图片，它也能完美工作。
测试阶段 (Test Mode) 必须依赖训练时积攒的全局 running_mean 和 running_var。 不需要任何 running 参数！ 测试时和训练时的行为一模一样，直接用当前样本自身的特征算均值方差即可。
适用场景 图像分类 (CNN)，Batch Size 较大的场景。 自然语言处理 (RNN, Transformer)，目标检测，Batch Size 极小或序列长度不固定的场景。
