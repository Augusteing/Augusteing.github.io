Operator Overloading  运算符重载

Python 中的 get_the_max 函数是通用的，可以作用于任何类型。它通过利用”运算符重载”实现了这种通用性。

更一般地，这种处理任何类型的能力有时被称为”多态”，我将通过维基百科来定义它。指的是：“编程中呈现相同编程接口以适应不同底层形式的能力” [wiki]

也就是说，我们有同样的 get_the_max 函数，但是有传入的数值有不同的类型。

在这种情况下，>运算符允许比较任何事物（即”任何底层形式”）。而>的定义由 __gt__ 给出。

我们刚刚使用的多态性有时被称为子类型多态性。

这里的思路是，一个超类型（ Comparable ）指定了能力（在这个例子中是比较能力）。然后一个子类型（ Dog ）重写了超类型的抽象方法。在运行时，Java 根据调用方法的对象的类型来决定要做什么。

Comparables vs. Comparators

Comparable 接口指定了存在“自然顺序”。该类的实例可以与其他对象进行比较。只可能存在一种这样的顺序。

Comparator 接口用于外部的比较（由其他类实现）。可能有多个此类类，每个类指定一种排序方式。

这是无法避免的，事实上，真实的 Java 库中通常有多个函数，每个原始类型一个。例如，存在 Arrays.sort(int[]) 、 Arrays.sort(double[]) 、 Arrays.sort(float[]) 等。也许有一天 Project Valhalla 会解决这个问题。
