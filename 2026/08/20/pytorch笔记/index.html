PyTorch 基础张量操作与代数直觉

这份笔记将 PyTorch 的核心操作融合成了更具连贯性的段落描述，在解释代码之前先梳理好背后的逻辑与数学直觉，非常适合在 Obsidian 中作为沉浸式阅读与查阅的素材。

在 PyTorch 的世界中，张量（Tensor）是最核心的数据载体。你可以将其视为一种可以在 GPU 上进行大规模并行加速计算的多维数组。从数学的视角来看，标量是零阶张量，向量是一阶张量，矩阵是二阶张量，而更高维度的数据（如包含批次、时间步和特征维度的数据）则是高阶张量。

张量的创建与初始化

在实际编写代码时，我们经常需要从零开始构建这些多维结构。最直观的方式是将现有的 Python 列表或 NumPy 数组直接转换为 PyTorch 张量。但在初始化模型参数或构建占位符时，我们更多地依赖框架提供的内置函数，快速生成特定大小和分布的张量。例如，我们可以轻松创建全零矩阵、全一矩阵，或是服从标准正态分布 $N(0, 1)$ 的随机矩阵。

形状观测与维度重塑

在处理张量运算时，对维度的精准控制是重中之重。了解一个张量的当前形状（Shape）往往是调试代码的第一步。很多时候，我们需要在不改变底层数据元素总数的前提下，重新定义张量的观测坐标系。比如，将一个长度为 $12$ 的一维向量折叠成一个 $3 \times 4$ 的矩阵。虽然 view() 和 reshape() 都能实现这一点，但对于新手而言，reshape() 更加健壮，因为它能自动处理内存不连续的情况。

另外，在利用广播机制（Broadcasting）对齐张量维度时，我们经常需要人为地插入或压缩大小为 $1$ 的“哑维度”。升维操作 unsqueeze 可以在指定位置插入新维度，而降维操作 squeeze 则会将多余的单维度剔除。若需要计算矩阵的转置 $A^T$，或是简单地交换某两个特定维度，则可以直接调用转置方法。

数据的拼接与堆叠

在处理批量数据时，我们通常需要将多个独立的张量组合在一起。PyTorch 提供了两种不同的组合逻辑：拼接（Concatenation）和堆叠（Stacking）。拼接是指在现有的某个维度上，将张量首尾相连地拼凑起来，这一过程不会改变张量的阶数（即维度的总数）。相比之下，堆叠则更为立体，它会引入一个全新的维度，将原来的张量像纸张一样垂直叠放起来，从而使整体的张量阶数增加一阶。

代数运算与聚合分析

张量的基础代数运算设计得极其直观。对于形状兼容的张量，常规的算术运算符（如加法、乘法）执行的都是逐元素（Element-wise）的运算。例如两个矩阵相乘，默认计算的是它们的哈达玛积（Hadamard Product）。如果你需要执行严谨的线性代数矩阵乘法（即计算点积 $C = A B$），则需要使用专用的 @ 符号或 matmul 函数。

在处理完数据后，我们经常需要沿着特定的轴提取统计信息，例如对某一维度的数值求和、求平均或寻找最大值。在调用这些聚合函数时，明确指定 dim 参数是非常关键的，它告诉 PyTorch 你希望沿着哪个维度进行“坍缩”计算。

数据流转：类型与设备

PyTorch 能够傲视群雄的一大原因，在于它让硬件加速变得异常简单。然而，在此之前必须遵循一个严格的物理法则：参与运算的所有张量，必须位于同一块硬件设备上（要么全在 CPU，要么全在同一块 GPU 上），并且它们的数据类型（例如 32 位浮点数或 64 位整数）也必须对齐。在模型训练和推理的过程中，通过 .to() 方法在不同设备或不同数据精度之间转移张量，是最常见的起手式。
