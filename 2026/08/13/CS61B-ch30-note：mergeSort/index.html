插入排序

原地插入排序的算法如下：

  • i 从 0 到 N-1 遍历：
    • 第 i 个元素之前是已排序元素部分，之后为未排序部分
    • 如果 i 元素 < i - 1 元素，则交换，直到第 i 个元素在正确的位置上

时间复杂度为 $O(N^2)$

值得一提的是：插入排序在小数组上表现十分良好，大约 N = 15、16时，插入排序应该是最快的方法，之所以是这样是因为：插入排序无需创造数组，只是在原地进行排序，所以其常数时间在实际上很小，也就是说一个小的常数时间 * N^2 < 大的常数时间 * N logN.

插入排序有一种自适应的性质，如果数组已经有序，那么插入排序可以利用这一点。

快速排序

之前，我们已经学习了选择排序、堆排序、归并排序和插入排序。

这些排序算法各自都有一个基本思想作为支撑：

  • 选择排序：找到最小的元素，将其放到最前面
  • 堆排序：使用最大优先队列（MaxPQ）找到最大元素，将其放到最前面
  • 归并排序：将两个已排序的半部分合并为一个有序的整体
  • 插入排序：确定当前元素应插入的位置

快速排序的核心思想涉及分区操作。

具体来说，要对数组 a[]进行分区，首先选择一个元素 x = a[i]作为基准（pivot）。

以该基准元素（x）进行分区涉及重新排列 a[]，使得：

  • x 移动到某个位置 j（可以是 i 的原始位置）
  • x 左侧的所有数组元素都小于或等于 x（<= x）
  • 分区后，数组中所有位于 x 右侧的元素都大于或等于 x（>= x）
