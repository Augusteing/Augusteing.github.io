CS231N lecture13 note：生成模型 1

监督 和 无监督

有监督学习我们已经见过很多的例子，比如说之前的图像分类，物体边缘识别等等都是有监督学习。

无监督学习或者自监督学习是让人感觉虚无缥缈的东西，我们要让模型学习到数据中的某种“特征”，听上去实在是让人难过。

像是 k-means 聚类、PCA 等算法都是经典的自监督学习。

判别模型和生成模型

判别模型本质上是在拟合数据分布，给定一个图像 $x$ 输出 $P(Y|X)$，输出该图像的概率分布 $x$。我们希望给正确的标签更高的概率，这也是 $softmax$ 函数的设计初衷。

值得一提的是：这里的概率分布是指针对于特定的图像 $x$ 而不是全体的图片，这一点会和之后的生成模型有所区别。

判别模型由于输出的列别都已经提前订好，所以即使你输入的是一条龙，也会分配 cat 这个标签的概率（甚至有可能挺高的）。

生成模型

生成模型的一个核心为：

我们有一个可观测（假定）的前验分布，$z$，我们希望创建一个从 $z ->x$ 的关联，并且直到如何从 $z$ 中采样。

生成模型对比判别模型是另一种思路：我们需要对一切有可能的事件建模，这也会导致概率空间非常巨大。

在生成任务中，我们的终极目标是从真实的未知数据分布 $p_{\text{data}}(x)$ 中采样出新的样本。但我们只有样本，没有 $p_{\text{data}}$ 的显式表达式。

自回归模型

数学解释

我们要通过参数 $W$ 去拟合真实的数据分布 $p(x) = f(x, W)$。

独立同分布假设与连乘积 给定数据集 $x^{(1)}, x^{(2)}, \dots, x^{(N)}$，假设它们是从真实分布中独立同分布（i.i.d.）抽样出来的。因此，整个数据集出现的联合概率（即似然函数）就是每个样本概率的连乘：
$$L(W) = \prod_{i} p(x^{(i)})$$
调整参数 $W$，让当前观测到的数据集出现的概率（即联合概率）最大化。

计算机在处理连乘时极易发生数值下溢（一堆小于1的小数连乘会迅速趋近于0）。 由于 $\log$ 函数是严格单调递增的，它不会改变极值点的位置，因此可以利用对数的性质将连乘转化为求和：

$$\arg\max_W \prod_{i} p(x^{(i)}) = \arg\max_W \sum_{i} \log p(x^{(i)})$$
这一点在作业中有所体现

最终目标为：

$$\arg\max_W \sum_{i} \log f(x^{(i)}, W)$$
注：实际上我们更乐意”最小化“损失函数，所以通常进一步处理为：

$$\text{Loss}(W) = -\sum_{i} \log f(x^{(i)}, W)$$

它不假设数据是什么类型，也不假设数据有什么结构。

自编码器 VAE

非分编码器

从输入数据中提取出一些特征向量 $z$ ，最后启用一个解码器重建 $x$，实际上就是恒等函数。
$$
x = x
$$
这个 $z$通常都很小，蕴含着关键的信息。

如果我们能利用这些 z 来生成新的 z，但是生成新的 z 也不比生成新的 x 简单多少。

自分编码器

假设我们观测到的原始数据 $x$ 背后，隐藏着一组不可观测的低维潜变量，VAE 不仅要“压”出特征，还要对 $z$ 的概率分布进行建模，从而能够通过采样创造出全新的数据。

具体生成过程如下：

  • 首先，从先验分布 $p_{\theta^*}(z)$ 中随机抽取（Sample）一个隐变量 $z^{(i)}$。
  • 然后，将这个 $z^{(i)}$ 输入到条件生成模型（解码器）中，通过条件概率分布 $p_{\theta^*}(x \mid z^{(i)})$ 采样或计算出对应的数据 $x$。

解码器负责给定隐变量 $z$，去重构或生成原始数据 $x$。这里将其建模为一个高斯分布

$$p_\theta(x \mid z) = \mathcal{N}(\mu_{x \mid z}, \sigma^2)$$

其中 $\mu_{x \mid z}$ 是由神经网络输出的均值（即重构出的图像/数据），$\sigma^2$ 通常假设为常数。

在理论上，我们真正需要的是真实的后验分布 $p_\theta(z \mid x)$（即“给定数据 $x$，它对应的隐变量 $z$ 应该是什么分布”）。但这个后验分布在数学上是不可解（Intractable）的。

因此，VAE 引入了一个由神经网络参数 $\phi$ 驱动的变分后验分布（Encoder） $q_\phi(z \mid x)$ 去逼近真实的后验分布，同样将其假设为高斯分布：

$$q_\phi(z \mid x) = \mathcal{N}(\mu_{z \mid x}, \Sigma_{z \mid x})$$

网络通过输入数据 $x$，输出该高斯分布的均值向量 $\mu_{z \mid x}$ 和协方差矩阵 $\Sigma_{z \mid x}$。

通过贝叶斯定理，边缘对数似然可以写成：

$$p_\theta(x) = \frac{p_\theta(x \mid z) p(z)}{p_\theta(z \mid x)}$$

因为真实后验 $p_\theta(z \mid x)$ 无法计算，幻灯片指出：_如果我们能通过 Encoder 确保 $q_\phi(z \mid x) \approx p_\theta(z \mid x)$_，我们就可以用 $q_\phi(z \mid x)$ 去近似它：

$$p_\theta(x) \approx \frac{p_\theta(x \mid z)p(z)}{q_\phi(z \mid x)}$$

$$\log p_\theta(x) \ge \mathbb{E}{z \sim q_\phi(z \mid x)} [\log p_\theta(x \mid z)] - D{KL}(q_\phi(z \mid x) \parallel p(z))$$
第一项：$\mathbb{E}_{z \sim q_\phi(z \mid x)} [\log p_\theta(x \mid z)]$：输入一张图 $x$，通过 Encoder 得到 $z$，再通过 Decoder 把 $z$ 还原成 $\hat{x}$。我们希望还原出来的 $\hat{x}$ 和原图 $x$ 越像越好。

第二项：$- D_{KL}(q_\phi(z \mid x) \parallel p(z))$：Decoder 的重建能力太强（比如用了一个极其强大的 PixelCNN 或 Transformer 作为解码器），它完全不需要 $z$ 的规律约束就能把图画好。
