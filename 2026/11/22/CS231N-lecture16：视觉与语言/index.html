CS231N lecture16：视觉与语言

基础模型

  • 基础模型通常对于许多任务都有很强的通用性
  • 这类模型通常具有很大的参数量。

Clip

回顾 SimCIR 这种自监督的对比学习框架，其希望图片和来自相同图片的内容在空间中有很近的关系，这样在做新的图像分类时，把其嵌入表示空间就可以得到与之类别相近的图片的位置。从而做图像分类

Clip 是 OpenAI 在 2021年发布的模型，其核心思路大致相同，只不过其训练目标是：图片和描述该图片的文字在空间中有很近的关系。

在表示空间中，我们也嵌入文本：

“A cute fluffy cat” 这句话肯定要和 猫 这个类别更近，这样我们就得到了使用文字查询图片的功能，这是多模态的大致思路之一。

使用图像和文本的关联来训练 Clip，在训练图像编码器时，也训练文本编码器。

CLip 由于学习到了图片和文字之间高维度的相互关系，所以也能用于很多的下游任务。

Clip 取得了很好的效果；

适配新任务

语言模型的特点

语言模型通常都是使用自动补全这个任务来训练的，对于下游任务来说，所有任务都可以是自动补全任务。

CLIp 适配新任务

但是 CLip 是用图文来训练的，该如何适配到下游呢？

假设要泛化到没有见过的新类别，我们可以这样设计：

利用文本编码器：将新类别词汇输入到 Text encoder，生成一个表示空间内的向量，这样输入新图像时，新图像和新类别具有很近的几何关系。

CLip 的强大

Clip 能在不同的数据集上（哪怕数据集中的数据有些冷门）表现都不错，ObjectNet 有很多诡异的图片（）

效果好的原因有以下几点：

  • 互联网上的文本对通常不仅仅只给出类别，还给出很多描述的信息。
  • 模型参数量很大，大约307 million
  • 训练数据图片大概 4亿张

缺点

Clip 的一个关键问题在于 batch size，如果我们一个 batch 中仅有猫和卡车，那么模型会非常容易就分辨出二者的区别，当我们的 batch size 更大时，就更容易出现和 猫 相近的类别，这会迫使模型学习到更深的内容。

**增大模型的负样本

但很遗憾的是，增大负样本有时候会使得模型具有很差的泛化性能，至今没有什么太好的解释。

Coca

Coca 是 clip 的一个变体模型，其在 文本编码器 和 图像编码器后新加了一个 多模态的文本编码器：输入图片 输出**描述文本。

这迫使模型要学习到更好的表示

视觉语言模型

语言模型大部分通过文本补全来训练模型，自动补全可以采用自监督的形式来进行。

我们希望图片视觉模型也是如此

LLaVa

如图所示，在利用基础 Transformer 模型时，先将图片过一遍 CLip 的视觉编码器，再接一个线性层，最后得到图片 token。

这样一起嵌入到 LLm 中，生成下一个词汇。

Flamingo

*Flamingo dance
如果你看过《成龙历险记》的话

Flamingo 对于 LLava 做了一些改进：

  • 将图片过了视觉编码器之后，再过一个 Perceiver，得到图片的某种表示
  • 将图片表示嵌入到 LLM 的每一层

当然我们需要对于 LLM 的层做一些改进：

门控机制

Flamingo 的图片门控机制可以描述如下：

视觉输入先过一个交叉注意力，之后再加入一个权重的门控机制即可。这样做的主要目的是为了使得模型具有选择图片元素的权力。
