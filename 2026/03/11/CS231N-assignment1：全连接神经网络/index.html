CS231N assignment1：全连接神经网络

网络定义

在构建深度学习模型时，一个稳健且高效的神经网络离不开精心设计的参数初始化。对于一个任意层数的多层感知机（Multilayer Perceptron, MLP）或全连接神经网络（Fully Connected Neural Network），其核心的可学习参数主要包括各层的权重矩阵（Weights）和偏置向量（Biases）。如果网络引入了批量归一化（Batch Normalization）等高级特性，还需要额外初始化相应的缩放与平移参数。

1. 权重与偏置的初始化原则

在全连接层中，数据的前向传播主要依赖于线性变换。假设某层的输入特征维度为 $D_{in}$，输出特征维度为 $D_{out}$，则该层的权重矩阵 $W$ 的形状应为 $(D_{in}, D_{out})$，而偏置向量 $b$ 的形状为 $(D_{out},)$。

为了打破神经网络的对称性（Symmetry Breaking），使得网络中不同的神经元能够学习到不同的特征，权重矩阵不能全部初始化为零。在实践中，我们通常从均值为 0、标准差为特定值（如代码中的 weight_scale）的高斯分布（正态分布）中随机采样来初始化权重：
$$W \sim \mathcal{N}(0, \text{weight_scale}^2)$$
相对而言，偏置向量通常可以安全地初始化为全零向量，因为权重的随机性已经足以打破对称性。

2. 批量归一化（Batch Normalization）的参数引入

随着网络层数的加深，内部协变量偏移（Internal Covariate Shift）问题会显著拖慢训练速度。为了解决这一问题，批量归一化技术被广泛应用。它在数据输入激活函数之前，将其强制拉回均值为 0、方差为 1 的标准分布。

然而，单纯的标准化可能会破坏网络原本学习到的特征表达能力。因此，批量归一化引入了两个全新的可学习参数：

  • **缩放参数 (Scale) $\gamma$**：用于控制归一化后数据的方差。

  • **平移参数 (Shift) $\beta$**：用于控制归一化后数据的均值。

经过归一化和线性变换后的输出可以表示为：
$$y = \gamma\hat{x} + \beta$$
其中，$\hat{x}$ 为零均值单位方差的输入数据。在网络初始化阶段，为了保证训练初期归一化层仅仅起到标准化的作用而不改变数据分布的尺度，我们通常将 $\gamma$ 初始化为全 1 向量，将 $\beta$ 初始化为全 0 向量。需要注意的是，批量归一化通常只应用于隐藏层，而不会应用于输出层（因为输出层需要输出原始的类别分数）。

3. 代码实现：模块化构建多层网络

基于上述理论，我们可以通过编程实现一个支持任意隐藏层维度 (hidden_dims) 和层数 (num_layers) 的通用初始化函数。为了逻辑的清晰性，以下代码将其分为三个部分进行构建：输入层到第一个隐藏层、中间隐藏层之间的传递，以及最后一个隐藏层到输出层的映射。

前向传播和反向传播

1. 前向传播 (Forward Pass)：数据的逐层映射

前向传播是神经网络根据当前权重对输入数据进行特征提取和分类的过程。在多层全连接网络中，数据像流水线上的产品一样，依次经过每一层的处理。

对于隐藏层，每一次处理都包含两个子步骤：首先是**线性变换 (Affine Transformation)，公式为 $Z = XW + b$；随后是非线性激活 (Non-linear Activation)**，通常使用 ReLU 函数 $A = \max(0, Z)$。通过引入非线性，网络才具备了拟合复杂函数的能力。而最后一层（输出层）只进行线性变换，直接输出每个类别的原始得分 (Scores)。

**核心工程技巧 (Caching)**：在计算前向传播时，必须将每一层的输入和中间变量保存下来（称为 cache）。这些中间变量在后续计算局部梯度时不可或缺。

2. 损失计算 (Loss Computation)：评估模型的表现

为了衡量模型预测值与真实标签之间的差距，我们需要定义损失函数 (Loss Function)。在分类任务中，通常采用 Softmax 损失（即交叉熵损失 Cross-Entropy Loss）。

为了防止模型过度拟合训练数据（Overfitting），我们还会在数据损失的基础上加上 **L2 正则化惩罚项 (L2 Regularization)**，迫使网络学习到更平滑、分散的权重。总损失公式如下：

$$L = L_{data} + \frac{1}{2} \lambda \sum_k \sum W_k^2$$

其中，$\lambda$ 对应代码中的超参数 self.reg。在工程实现上，为了避免复杂的求导和潜在的数值溢出问题，我们通常会调用底层封装好的高度优化的 softmax_loss 函数，它不仅能计算出数据损失，还能同时返回损失关于得分的偏导数 dscores，作为反向传播的起点。

具体损失如何计算见上，其中请注意，我们一般不使用取正确类的指数概率的负对数作为求损失的方法。这是因为shift_scores = scores - np.max(scores, axis=1, keepdims=True)操作可能会导致部分值为一个绝对值较大的负数，而exp_scores = np.exp(shift_scores)会导致某些值为0，这样在求负对数时，最后的loss可能会为inf

3. 反向传播 (Backward Pass)：误差的逆向传递与参数更新

反向传播是神经网络学习的核心所在，其数学本质是**微积分中的链式法则 (Chain Rule)**。我们将最终的损失视为一个“信号”，让它从网络的输出端反向流回输入端。

在代码实现中，我们不需要为每一层定义繁琐的梯度变量列表。相反，可以只用一个变量 dout 来扮演“水管”的角色，承接从上一层传下来的梯度。我们按照与前向传播完全相反的顺序（即从第 $N$ 层倒推回第 $1$ 层），依次从 cache 列表中取出中间变量，计算局部梯度。

特别需要注意的是，由于损失函数中包含了 L2 正则化项，因此在计算权重矩阵的梯度时，必须加上正则化项的导数：

$$\frac{\partial L}{\partial W} = \left(\frac{\partial L_{data}}{\partial W}\right) + \lambda W$$

5层网络和3层网络的对比

问题：你是否注意到三层网络和五层网络在训练难度上的比较？特别是，根据你的经验，哪个网络似乎对初始化规模更敏感？你认为为什么会这样？

5 层网络比 3 层网络在训练难度上大得多，而且对初始权重比（weight_scale）的敏感度呈指数级增加。

我们可以从前向传播（信号传递）和反向传播（梯度传递）两个角度来剖析这个现象。在神经网络中，数据穿越每一层时，本质上都在经历矩阵乘法：

$$H = X \cdot W_1 \cdot W_2 \cdot \dots \cdot W_n$$

由于 5 层网络比 3 层网络多了两层连乘，这就引发了著名的蝴蝶效应：请见lecture6 note1，介绍了何凯明方法。

SGD + Momentum

在训练深度神经网络时，最基础的优化算法是**随机梯度下降 (Vanilla SGD)**。它的规则非常简单粗暴：算出当前位置的梯度，然后逆着梯度的方向走一步。 公式为：$x_{next} = x - \text{learning_rate} \times dx$

1. 基础 SGD 的致命缺陷

虽然 SGD 简单易用，但在实际复杂的“损失函数地形”中，它面临着两个巨大的挑战：

  • 峡谷震荡 (Ravines/Valleys)： 假设地形是一个狭长的峡谷，坡度在一个方向上很陡峭，而在另一个真正通向最低点的方向上却很平缓。SGD 会在陡峭的峡谷两壁之间来回反复横跳（震荡），而在真正该前进的平缓方向上却走得极其缓慢。

  • 局部最优与鞍点 (Local Minima & Saddle Points)： 如果遇到一个平坦的小坑或马鞍面，梯度 $dx$ 变成了 0。此时 SGD 会直接停在原地，彻底“死机”，再也无法继续训练。

2. 动量法 (Momentum) 的物理直觉

为了克服这些致命缺陷，研究人员从经典物理学中汲取了灵感，引入了动量（Momentum的概念。你可以将损失函数的优化过程想象成将一个小球从山顶滚下。标准的 SGD 就像是一个没有质量的物体，每移动一步都需要完全依赖当前的坡度；而动量法则是赋予了这个小球“质量”与“惯性”。当小球沿着坡度滚下时，它会不断积累速度。在梯度方向频繁改变的维度上（如峡谷的两壁），历史速度和当前梯度的方向相反，使得震荡被有效抵消；而在梯度方向一致的维度上，速度会不断叠加，推动小球以越来越快的速度冲向谷底，甚至能够凭借惯性冲出较浅的局部最优陷阱。
下
在数学上，动量法通过引入一个速度变量 $v$ 来模拟这一物理过程。设当前时刻的权重为 $w_t$，当前计算出的梯度为 $dw$，学习率为 $\alpha$。我们还需要一个超参数 $\mu$（通常被称为动量系数或衰减率，常见取值为 $0.9$），它类似于物理环境中的摩擦力或空气阻力，用于防止速度无限制地增长。动量法的参数更新规则由以下两个公式构成。首先，我们要计算当前的新速度 $v_{t+1}$，它等于受摩擦力衰减后的历史速度加上当前梯度带来的新动力：

$$v_{t+1} = \mu v_t - \alpha dw$$

随后，我们利用计算出的新速度来更新当前的权重参数，得到下一步的位置 $w_{t+1}$：

$$w_{t+1} = w_t + v_{t+1}$$

在代码实现层面，这套精美的数学逻辑被完美地封装在了 update(w, dw, config) 这个统一的 API 接口中。由于动量法的核心在于“记住过去的速度”，而单纯的函数调用在结束后会销毁局部变量，因此接口中的 config 字典就扮演了至关重要的状态记忆库角色。

在每次调用该 API 时，程序首先会从 config 中提取出基础超参数：学习率 $\alpha$ (config['learning_rate']) 和动量系数 $\mu$ (config['momentum'])。更关键的是，它会读取上一次迭代保留下来的历史速度 $v_t$ (config.get('velocity', 0))。接着，程序根据上述数学公式，利用输入的当前权重 w 和当前梯度 dw 计算出新的速度和新的权重 next_w。最后，为了让下一次迭代能够继续利用这份动量，程序必须将刚刚算出的新速度覆写回 config['velocity'] 中，并将更新后的 next_w 与 config 一同返回。通过这种设计，优化器便能在无数次迭代中连贯地传递状态，完成“滚雪球”般的优化过程。

有关为什么是减去学习率乘以梯度

在数学上，损失函数关于权重的梯度 $dw$ 有：梯度永远指向函数值增加最快的地方（即最陡峭的“上坡”方向）。

假设你现在站在半山腰，蒙着眼睛。你用脚探了探周围，发现往东走最陡峭、最费力。那么，此时你所在位置的梯度 $dw$ 就是“正东方”。

在训练神经网络时，我们的目标是**最小化损失函数 (Minimize Loss)**，也就是要走到山谷的最底端。

既然梯度 $dw$ 指向的是上坡，那我们要下坡，就必须逆着梯度的方向走。

这就是为什么在最基础的梯度下降（SGD）中，更新公式是减号：

$$w_{next} = w - \alpha \cdot dw$$

（当前的坐标，减去上坡的方向，就等于往下坡走了一步）。

Adam is all you need

在前面的学习中，我们引入了动量法（Momentum）来加速梯度的下降并减少震荡。然而，SGD 及其动量变体依然存在一个局限性：它们对网络中的所有参数都使用同一个全局的“学习率”。在深层网络中，不同参数的梯度量级往往差异巨大——有些方向的梯度非常陡峭，需要较小的步伐以免越过极小值；而有些方向极其平缓，需要极大的步伐才能加速收敛。为了解决这个问题，研究人员提出了自适应学习率（Adaptive Learning Rate算法，其中最著名的代表便是 RMSProp 和 Adam。

第一部分：RMSProp (Root Mean Square Propagation)

RMSProp 的核心思想是动态调整每个参数的学习率：对于梯度一直很大的参数，降低其学习率；对于梯度一直很小的参数，提高其学习率。为了实现这一点，RMSProp 引入了“梯度二阶矩的滑动平均值（Running average of squared gradients）”。简单来说，它不仅看当前的梯度大小，还要记录历史梯度的平方和。

在数学上，设当前梯度为 $dw$，学习率为 $\alpha$。我们引入一个衰减率超参数 $\text{decay_rate}$（通常设为 $0.99$），以及一个用于记录历史平方梯度的缓存变量 $v$（初始为 0）。在每一步迭代中，首先更新平方梯度的滑动平均值：

$$v_{t+1} = \text{decay_rate} \cdot v_t + (1 - \text{decay_rate}) \cdot dw^2$$

接着，在更新权重参数时，我们将全局学习率除以历史平方梯度的平方根。为了防止分母为零导致程序崩溃，必须加上一个极小的平滑常数 $\epsilon$（epsilon，通常设为 $10^{-8}$）。权重 $w$ 的更新公式为：

$$w_{t+1} = w_t - \frac{\alpha}{\sqrt{v_{t+1}} + \epsilon} \cdot dw$$

对于 $w$ 里面的每一个单独的参数（比如 $w_{0,0}$），它都对应着一个专属的梯度 $dw_{0,0}$ 和一个专属的历史累积值 $v_{0,0}$。公式的意思是： 把基础学习率 $\alpha$ 除以 $\sqrt{v_{0,0}} + \epsilon$，算出 $w_{0,0}$ 此刻专属的实际学习率，然后再乘以它的梯度 $dw_{0,0}$

在 API 接口中的实现细节： 在 rmsprop 函数中，需要从 config 字典中提取 config['learning_rate']、config['decay_rate'] 和 config['epsilon']。同时，历史累积变量 $v$ 会被存储在 config['cache'] 中（如果不存在则初始化为全 0 矩阵）。更新完成后，务必将新的 $v$ 存回 config['cache'] 并返回。

它和动量法最大的区别就是会动态更新每个参数的学习率

第二部分：Adam (Adaptive Moment Estimation)

如果说 Momentum 是给优化过程加了“惯性”，RMSProp 是给每个参数加了“自适应刹车”，那么 Adam 则是这两者的集大成者。Adam 同时维护了梯度的一阶矩（First Moment，即带有动量的梯度均值和二阶矩（Second Moment，即 RMSProp 中的历史平方梯度）。

在数学推导中，Adam 引入了两个衰减率：$\beta_1$（通常为 $0.9$，用于一阶矩）和 $\beta_2$（通常为 $0.999$，用于二阶矩）。设一阶矩为 $m$，二阶矩为 $v$。在每一步迭代中，它们的更新公式如下：

$$m_{t} = \beta_1 \cdot m_{t-1} + (1 - \beta_1) \cdot dw$$

$$v_{t} = \beta_2 \cdot v_{t-1} + (1 - \beta_2) \cdot dw^2$$

关键机制：偏差校正 (Bias Correction)

由于 $m$ 和 $v$ 在训练初期都被初始化为 0，这会导致它们在最初的几次迭代中严重偏向于 0（尤其是当衰减率 $\beta$ 接近 1 时）。为了抵消这种初始偏差，Adam 引入了时间步 $t$（当前是第几次迭代，从 1 开始）。我们需要对 $m$ 和 $v$ 进行偏差校正，得到无偏估计量 $\hat{m}$ 和 $\hat{v}$：

$$\hat{m}_t = \frac{m_t}{1 - \beta_1^t}$$

$$\hat{v}_t = \frac{v_t}{1 - \beta_2^t}$$

最后，结合动量和自适应学习率的优势，利用校正后的变量来更新权重：

$$w_{t+1} = w_t - \frac{\alpha}{\sqrt{\hat{v}_t} + \epsilon} \cdot \hat{m}_t$$

有关为什么这么设计

adam 实际上综合了两种设计：

1.动量法：不只是依靠于 $dw$，还依靠历史速度。这就像是给跑车装上了极具质量的车身和精准的方向盘。即使当前这一脚油门踩歪了（当前 batch 的梯度有噪音），由于历史惯性 $m_t$ 的存在，车子依然会平稳地顺着大方向（真正的谷底）开。它不仅过滤了噪音，还完美抵消了在峡谷地形中的来回震荡。

2.rmsprop：在深层神经网络中，有成千上万、甚至上亿个参数。这导致了一个致命问题：不同参数的坡度差异极大。有些参数所在的维度极其陡峭，稍微动一下就会飞出去；有些参数的维度极其平缓，走半天都在原地踏步。如果所有的参数都共用同一个学习率 $\alpha$，必然顾此失彼。它记录了每个参数历史梯度的平方和 $v_t$（二阶矩）。然后在更新时，把全局学习率除以 $\sqrt{v_t}$。

  • 如果某个参数过去一直剧烈抖动、梯度很大（$v_t$ 很大），分母变大，它的专属学习率就会被压低（踩刹车），防止它越过最优解。

  • 如果某个参数过去一直像死水一样、梯度很小（$v_t$ 很小），分母变小，它的专属学习率就会被放大（踩油门），帮助它快速赶上大部队。这就是“自适应（Adaptive）”的魔力。

在 API 接口中的实现细节：

在 adam 函数的 config 字典中，你需要维护更多的状态。除了 learning_rate、beta1、beta2 和 epsilon 之外，你还需要持久化保存三个变量：

  1. config['m']：一阶矩（初始为 0）。

  2. config['v']：二阶矩（初始为 0）。

  3. config['t']：时间步计数器（初始为 0）。**每次调用 update 函数时，第一件事就是将 config['t'] += 1**。
