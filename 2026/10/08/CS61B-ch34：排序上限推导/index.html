排序的上限

目前我们已经看到许多的算法，似乎他们的时间上线都是 $\theta(nlogn)$

最直观的用途当然是将事物按特定顺序排列。

  • 但它也可以用来解决其他任务，有时是以非常巧妙（non-trivial）的方式：

    • 排序将“查找重复项”问题的复杂度从朴素的 $O(N^2)$ 优化到了 $O(N \log N)$。

    • 排序将“3SUM”问题的复杂度从朴素的 $O(N^3)$ 优化到了 $O(N^2)$。

  • 对数组进行排序有许多种方法，每种方法都有其独特的权衡取舍（tradeoffs）和算法特性。

今天我们将讨论排序问题本身的根本性质：排序到底有多难？（即基于比较的排序算法的理论复杂度下界）。

数学证明

引理一：

存在正实数常数 $c > 0$ 和 $N_0 > 0$，使得对于所有 $N \ge N_0$，都满足 $N! \ge c \cdot \left(\frac{N}{2}\right)^{\frac{N}{2}}$。

  • 对原不等式两边取自然对数，命题等价于证明：
    $$\ln(N!) \in \Omega\left( \frac{N}{2} \ln\left(\frac{N}{2}\right) \right)$$

  • 展开左边：$\ln(N!) = \sum_{i=1}^N \ln i$。

    由于 $f(x) = \ln x$ 是严格单调递增函数，可以用定积分作为黎曼和的下界：

    $$\sum_{i=1}^N \ln i > \int_{1}^N \ln x , dx$$

  • 使用分部积分法计算定积分：

    $$\int_{1}^N \ln x , dx = \left[ x \ln x - x \right]_1^N = N \ln N - N + 1$$

    因此，$\ln(N!) > N \ln N - N + 1$。

  • 现在我们需要证明该下界在渐近意义上主导目标函数 $\ln\left(\left(\frac{N}{2}\right)^{\frac{N}{2}}\right)$：

    目标函数展开为：$\frac{N}{2} \ln\left(\frac{N}{2}\right) = \frac{N}{2} \ln N - \frac{N}{2} \ln 2$。

    比较两者之差：

    $$(N \ln N - N + 1) - \left( \frac{N}{2} \ln N - \frac{N}{2} \ln 2 \right) = \frac{N}{2} \ln N - N \left(1 - \frac{\ln 2}{2}\right) + 1$$

    由于 $\lim_{N \to \infty} \frac{N \left(1 - \frac{\ln 2}{2}\right)}{\frac{N}{2} \ln N} = 0$，可知当 $N$ 足够大时，$\frac{N}{2} \ln N$ 项占据绝对主导地位，差值必然大于 $0$。

引理二

1. 对前置条件两边取对数 已知 $N! > \left(\frac{N}{2}\right)^{\frac{N}{2}}$。由于对数函数 $\log(x)$（假设底数大于 1）是在其定义域上严格单调递增的，我们可以对不等式两边同时取对数，且不等号方向保持不变：

$$\log(N!) > \log\left(\left(\frac{N}{2}\right)^{\frac{N}{2}}\right)$$

2. 展开并化简右侧表达式

利用对数的幂法则 $\log(a^b) = b \log a$ 将指数提取至外侧：

$$\log(N!) > \frac{N}{2} \log\left(\frac{N}{2}\right)$$

接着，利用对数的商法则 $\log(\frac{a}{b}) = \log a - \log b$ 将其展开，分离出主导项：

$$\frac{N}{2} \log\left(\frac{N}{2}\right) = \frac{1}{2} N (\log N - \log 2) = \frac{1}{2} N \log N - \frac{\log 2}{2} N$$

3. 基于 $\Omega$ 定义的严格放缩

根据渐近下界 $\Omega$ 的定义，我们需要证明存在正实数常数 $c > 0$ 和阈值 $N_0 > 0$，使得当 $N \ge N_0$ 时，$\log(N!) \ge c \cdot (N \log N)$ 恒成立。

我们目前已经得到：

$$\log(N!) > \frac{1}{2} N \log N - \frac{\log 2}{2} N$$

为了用 $N \log N$ 的常数倍来建立下界，我们需要通过放缩去吸收掉尾部的负常数项 $-\frac{\log 2}{2} N$。我们可以通过拆分主导项的系数来实现，例如选取一个比 $\frac{1}{2}$ 小的系数 $c = \frac{1}{4}$。

我们需要找到满足以下不等式的 $N_0$：

$$\frac{1}{2} N \log N - \frac{\log 2}{2} N \ge \frac{1}{4} N \log N$$

对不等式进行移项整理：

$$\frac{1}{4} N \log N \ge \frac{\log 2}{2} N$$

两边同时除以 $\frac{1}{4} N$（由于探讨的是渐近性，可假定 $N > 0$）：

$$\log N \ge 2 \log 2$$

$$\log N \ge \log 4$$

这说明，只要 $N \ge 4$，该放缩就严格成立。

结合最初的推导，我们证明了当 $N \ge 4$ 时：

$$\log(N!) > \frac{1}{4} N \log N$$

引理三

  • $\log(N!) = \sum_{i=1}^N \log(i)$

  • $N \log N = \sum_{i=1}^N \log(N)$

由于对于任意整数 $1 \le i \le N$，都恒有 $\log(i) \le \log(N)$，所以只要对连加式中的每一项都取最大值进行放缩，就能得到一个严格的上界：

$$\log(N!) \le N \log N$$

这直接证明了 $N \log N$ 在渐近意义上是 $\log(N!)$ 的上界，也就是 $N \log N \in \Omega(\log(N!))$（或者更常见的表达方式：$\log(N!) \in O(N \log N)$）。

为什么要做数学推导

到目前为止，我们所讨论过的最快排序算法的最坏情况时间复杂度为 Θ(N∗logN)。这就引出了一个问题：我们能否得到一种具有更优渐近分析的排序算法？

信息论的绝对下界：对 $N$ 个不同的元素进行排序，总共有 $N!$ 种可能的排列组合。任何基于“两两比较”的算法，其底层都可以画成一棵决策树（Decision Tree）。为了能分辨出这 $N!$ 种结果，决策树的叶子节点至少要有 $N!$ 个。那么这棵树的深度（也就是最坏情况下的比较次数）至少是 $\log(N!)$。（其中log以2为底）

理论与现实的桥梁：通过刚刚的一系列放缩证明，我们确认了 $\log(N!) \in \Theta(N \log N)$。这意味着，排序问题的绝对理论下界，在渐近复杂度上就是 $N \log N$。

算法的最优性：像归并排序（Merge Sort）和快速排序（Quick Sort，期望复杂度）的时间复杂度已经是 $O(N \log N)$。结合前面两点，这就在数学上严格证明了：这些算法在渐近意义上已经是完美的。不可能再有人能发明出时间复杂度为 $O(N)$ 的纯比较排序算法了。
